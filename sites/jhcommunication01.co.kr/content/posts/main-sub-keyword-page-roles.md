## 메인키워드와 서브키워드는 무엇이 다른가요?

메인키워드는 사이트가 다루는 넓은 분야를 나타냅니다. 서브키워드는 그 분야 안의 서비스, 상황, 시점, 지역처럼 방문자의 질문을 구체화하는 말입니다. 병원 마케팅 대행사가 키워드를 정리할 때에도 이 구분이 출발점이 됩니다.

두 가지를 연결하려고 모든 글에 같은 단어를 반복하면 오히려 글끼리 역할이 겹칩니다. 먼저 페이지가 어떤 질문에 답하는지를 정하고, 그다음에 어떤 단어가 어울리는지 고르는 순서가 자연스럽습니다. 이렇게 역할을 먼저 적어 두면 새 글을 기획할 때 기존 글과 겹치는 부분이 쉽게 드러나고, 불필요한 글을 만드는 일도 줄어듭니다.

## 메인 페이지와 세부 글은 무엇을 나누어 담나요?

메인 서비스 페이지에는 제공 범위와 주요 선택 기준을 담습니다. 세부 글은 한 가지 질문에 답하고, 기준 페이지의 해당 항목으로 이어지도록 만듭니다. 예를 들어 치과라는 넓은 주제 아래 예약 절차와 치료 후 관리가 있다면 두 글에서 독자가 하려는 행동은 달라야 합니다.

지역명과 서비스명을 모든 제목에 똑같이 붙여도 서로 다른 답이 없다면 그것은 중복입니다. 제목만 바꾼 글이 늘어나면 방문자도 검색 환경도 어느 글이 기준인지 구분하기 어렵습니다.

## 내부 링크는 어떤 기준으로 연결해야 하나요?

링크는 관련성이 있는 문단에서 연결합니다. 독자가 비용 조건을 읽다가 최신 안내를 확인하고 싶어질 때 비용 안내 페이지로 넘어갈 수 있어야 합니다. 상위 페이지에서 하위 글로, 하위 글에서 정확한 기준 페이지로 돌아갈 수 있는지도 살펴봅니다.

링크 문구에 같은 키워드를 기계적으로 반복하거나 관련 없는 페이지를 수십 개 연결하면 탐색이 어려워집니다. 한 페이지에서 나가는 링크가 너무 많으면 선택지가 흐려지므로, 병원 마케팅 대행사가 점검할 때에는 링크 수보다 독자가 이어서 읽을 만한 길인지를 먼저 봅니다.

## 키워드 지도를 만든 뒤에는 무엇을 대조하나요?

키워드 지도를 만든 뒤에는 글 제목보다 실제 본문을 대조합니다. 두 페이지가 같은 설명을 하고 있는지, 오래된 정보가 서로 충돌하는지를 살핍니다. 제목은 달라도 본문이 같은 답을 하고 있다면 하나로 합치는 편이 방문자에게 낫습니다.

검색 결과의 위치는 여러 요인의 영향을 받습니다. 그래서 특정 구성만으로 노출 순위를 보장할 수는 없습니다. 키워드의 연결은 검색엔진뿐 아니라 사람이 필요한 답을 따라갈 수 있게 하는 정보 구조라는 관점에서 평가해야 합니다.

## 서브키워드는 어떤 기준으로 고르고 나누나요?

서브키워드는 단어의 크기보다 답의 차이를 기준으로 고릅니다. 표현이 달라도 같은 답이라면 한 페이지에서 함께 설명하고, 조건이 달라져 답이 바뀌면 별도 문서로 나눕니다. 이렇게 하면 글의 수를 억지로 늘리지 않아도 됩니다.

키워드를 배치한 뒤에는 검색자 입장에서 메뉴를 직접 따라가 봅니다. 넓은 설명에서 세부 조건으로 내려가는 경로와, 세부 질문에서 공식 안내로 돌아오는 경로가 모두 필요합니다. 글을 합치거나 주소를 바꿀 때에는 기존 링크를 함께 점검합니다. 정리한 기준은 담당자가 바뀌어도 같은 방식으로 이어 갈 수 있도록 문서로 남겨 둡니다.

## 자주 묻는 질문

### 메인키워드는 모든 글에 넣어야 하나요?

그렇지 않습니다. 메인키워드는 서비스 소개처럼 넓은 분야를 다루는 페이지에 두고, 세부 글에서는 그 글이 답하는 질문에 맞는 표현을 씁니다.

### 병원 마케팅 대행사는 키워드 지도를 어떻게 관리하나요?

페이지별로 담당하는 질문과 연결할 기준 페이지를 적어 둡니다. 새 글을 추가할 때마다 기존 글과 답이 겹치는지 대조해 갱신합니다.

### 지역명과 서비스명을 제목에 모두 붙이면 안 되나요?

붙여도 되지만 글마다 다른 답이 있어야 합니다. 본문이 같다면 제목만 달라도 중복으로 읽힐 수 있습니다.

### 내부 링크는 몇 개까지가 적당한가요?

정해진 개수는 없습니다. 독자가 다음에 확인할 만한 곳만 관련된 문단에서 연결하고, 선택지가 흐려질 정도로 늘리지 않습니다.

### 두 글의 내용이 비슷하면 어떻게 하나요?

같은 질문에 같은 답을 하고 있다면 하나로 합치고 기존 주소에서 새 주소로 연결합니다. 조건이 다르면 각 글의 범위를 분명히 나눕니다.

### 이 방법을 쓰면 검색 순위가 오르나요?

순위는 여러 요인의 영향을 받으므로 특정 구성만으로 보장할 수 없습니다. 방문자가 필요한 답을 따라갈 수 있는 구조를 만드는 것이 목적입니다.
