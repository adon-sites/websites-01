## 상태 등급만 적으면 구매자는 무엇을 알 수 없나요?

등급이라는 말은 판매자마다 기준이 달라 같은 A급이라도 의미가 다릅니다. 구매자는 어떤 부분이 새것에 가깝고 어떤 부분이 사용감이 있는지 알 수 없어 결국 문의로 다시 물어야 합니다.

등급을 쓴다면 외관, 기능, 구성품, 수리 이력처럼 확인 가능한 기준을 함께 밝혀야 합니다. 같은 등급 안에서도 구매 선택에 영향을 주는 흠집이나 제한이 있다면 숨기지 않고 적습니다.

## 작동 여부는 어떻게 확인하고 표시하나요?

먼저 판매할 물건의 실제 작동을 확인합니다. 전원이 켜진다는 사실과 모든 기능이 정상이라는 주장은 다릅니다. 시험하지 못한 기능은 미확인으로 표시하고 작동을 장담하는 표현은 쓰지 않습니다.

수리나 부품 교체 이력이 있다면 확인된 범위에서만 적습니다. 소유권이나 거래가 제한된 물건인지도 판매 전에 확인합니다. 온라인종합광고실행사가 판매 글을 점검할 때도 확인한 사실과 확인하지 못한 사실을 나눠 쓰는지부터 봅니다.

[표] 판매 글에서 확인 상태를 나눠 쓰는 방법
| 항목 | 확인한 경우 | 확인하지 못한 경우 |
| --- | --- | --- |
| 전원과 기본 기능 | 확인한 날짜와 함께 적기 | 미확인으로 표시 |
| 외관 상태 | 부위별로 나누어 적기 | 사진에 보이는 범위만 적기 |
| 수리 이력 | 확인된 범위의 이력 적기 | 알 수 없다고 적기 |
| 거래 제한 여부 | 확인 결과 적기 | 판매 전 확인 필요로 표시 |

## 외관과 구성품은 어떻게 보여 주고 나누나요?

외관은 사진으로 보여 주되 조명 때문에 흠집이 가려지지 않게 촬영합니다. 모서리, 화면, 연결 단자처럼 상태 차이가 큰 부위를 따로 설명할 수 있습니다. 등급표의 기준을 먼저 제시하고 각 상품의 개별 결함은 별도로 적습니다.

포함 품목과 제외 품목은 나눠 적습니다. 사진에 보이는 상자와 충전기, 액세서리가 모두 거래에 포함되는지 밝히고, 보증서가 있다면 양도할 수 있는지와 유효 기간을 확인합니다. 임의로 보증을 약속하지 않습니다.

구성품은 사진과 글의 내용이 어긋나지 않아야 합니다. 사진에는 있지만 거래에는 포함되지 않는 물건이 있다면 그 사실을 사진 가까이에 적어 구매자가 착각하지 않게 합니다.

## 등급 표기는 화면에서 어떻게 배치하나요?

모바일에서 등급만 크게 보이고 중요한 결함이 아래쪽에 숨지 않게 배치합니다. 여러 물건을 비교표로 보여 준다면 각 항목의 뜻과 단위를 같게 맞춥니다. 항목마다 기준이 다르면 비교표가 오히려 오해를 만듭니다.

품절된 상품은 거래 가능한 목록에서 상태를 바꾸고 오래된 글의 연락 경로도 정리합니다. 이미 거래가 끝난 글에 문의가 이어지지 않도록 하기 위해서입니다.

등급 기준표는 판매 글마다 새로 쓰기보다 한 곳에 두고 연결하면 관리가 쉽습니다. 기준이 바뀌면 표만 고치고, 바뀐 날짜를 함께 남겨 글마다 다른 기준이 쓰이지 않게 합니다.

| 점검 항목 | 좋은 배치 | 피해야 할 배치 |
| --- | --- | --- |
| 등급 표기 | 기준표와 함께 보이게 하기 | 등급만 크게 강조하기 |
| 개별 결함 | 등급 바로 근처에 적기 | 아래쪽 끝에 숨기기 |
| 비교표 | 항목의 뜻과 단위를 통일 | 항목마다 기준이 다름 |
| 품절 상품 | 목록에서 상태 변경 | 연락 경로를 그대로 두기 |

## 거래 직전에는 무엇을 다시 확인하나요?

판매 글은 거래 직전에 다시 확인합니다. 사용 중인 물건이라면 주행거리나 배터리 상태처럼 변할 수 있는 값이 있고, 전자기기라면 계정 잠금이나 초기화 여부도 구매자의 사용에 영향을 줍니다. 가격과 배송, 반품 조건은 실제 거래 방식과 적용되는 법규에 맞는지 검토합니다.

상태 등급은 좋은 인상을 붙이는 말이 아니라 실제로 확인한 사실과 남은 불확실성을 정리하는 도구입니다. 처음 보는 구매자가 글과 사진만 읽고도 어떤 기능을 확인하지 못했는지 알 수 있어야 합니다.

## 자주 묻는 질문

### 등급 표기를 아예 쓰지 않는 편이 낫나요?

꼭 그렇지는 않습니다. 등급을 쓰되 기준표를 함께 제시하고 개별 결함은 따로 적으면 구매자가 상태를 비교하기 쉬워집니다.

### 확인하지 못한 기능은 어떻게 적나요?

미확인이라고 분명히 적고 작동을 장담하지 않습니다. 확인하지 못한 부분을 밝히는 편이 거래 뒤의 분쟁을 줄이는 데 도움이 됩니다.

### 온라인종합광고실행사가 판매 글을 맡을 때 무엇을 요청해야 하나요?

확인한 사실과 확인하지 못한 사실을 구분해 전달해야 합니다. 온라인종합광고실행사는 받은 정보를 바탕으로 글을 정리하므로 상태 자료의 정확성은 판매자가 먼저 점검합니다.

### 사진은 어떤 점에 주의해서 찍나요?

조명 때문에 흠집이 가려지지 않게 하고 모서리, 화면, 연결 단자처럼 차이가 큰 부위를 따로 찍습니다. 사진에 보이는 구성품이 모두 포함되는지도 글에 적습니다.

### 미사용에 가까움 같은 표현을 써도 되나요?

실제 사용 이력과 맞는 경우에만 씁니다. 사용 흔적이 있는데도 그런 표현을 쓰면 구매자가 상태를 잘못 이해할 수 있어 신뢰를 잃게 됩니다.

### 글을 올린 뒤에도 점검이 필요한가요?

필요합니다. 거래 직전에 변할 수 있는 값을 현재 상태로 고치고, 거래가 끝난 글은 목록에서 상태를 바꿔 문의가 이어지지 않게 정리합니다.
