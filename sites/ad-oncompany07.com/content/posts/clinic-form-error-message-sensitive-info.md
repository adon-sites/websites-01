## 오류 화면도 개인 정보를 다루는 화면입니다

의료기관 홈페이지의 문의 양식에서 전화번호 형식이 틀리거나 필수 칸이 비어 있으면 오류 화면이 나타납니다. 이때 일부 양식은 사용자가 적은 내용을 그대로 다시 보여 주면서 어디가 잘못됐는지 알려 줍니다. 편리해 보이지만, 증상이나 검사 결과를 적은 사람에게는 그 내용이 화면 가득 다시 펼쳐지는 셈입니다.

여러 사람이 함께 쓰는 공용 컴퓨터나 가족이 함께 쓰는 휴대전화라면 다른 사람이 그 화면을 볼 수 있습니다. 화면을 캡처해 문의하는 과정에서 민감한 내용이 의도치 않게 공유되기도 합니다. 문의 양식 오류 문구는 고쳐야 할 지점을 알려 주되, 건강 정보를 불필요하게 반복하지 않도록 설계해야 합니다.

오류 화면을 단순한 기술 문제로만 보지 말고, 방문자의 정보를 다루는 공개 안내의 일부로 바라보는 관점이 필요합니다. 그래야 점검할 때도 개인 정보 보호를 기준에 넣게 됩니다.

## 먼저 수집하는 항목을 줄입니다

오류 문구를 고치기 전에 양식이 무엇을 받고 있는지부터 살펴봅니다. 예약 가능한 시간만 확인하면 되는 양식인데 긴 증상 설명을 필수 칸으로 받고 있다면, 오류 문구보다 수집 목적을 다시 검토하는 것이 먼저입니다. 받지 않아도 되는 정보는 처음부터 받지 않는 편이 가장 안전합니다.

자유롭게 적는 칸이 꼭 필요하다면 칸 옆에 안내를 둡니다. 진료 기록이나 검사 결과를 자세히 적지 않아도 된다는 점, 개별적인 판단이 필요한 내용은 진료나 전화 상담에서 다룬다는 점을 알려 주면 사용자가 스스로 입력 범위를 조절할 수 있습니다.

## 고칠 곳만 짚어 주는 문구로 바꿉니다

오류 메시지는 해당 입력 칸 바로 옆에 무엇을 고쳐야 하는지 짧게 적습니다. 전화번호 형식을 확인해 주세요, 이름 칸이 비어 있습니다처럼 고칠 항목만 짚어 주는 문의 양식 오류 문구면 충분합니다. 사용자가 입력한 전체 문장을 오류 메시지의 제목이나 요약에 다시 옮겨 적지 않습니다.

자동 회신 메일이나 문자도 같은 기준으로 점검합니다. 접수 확인 메시지에 사용자가 적은 증상 설명이 그대로 담겨 있다면 그 메시지가 다른 기기나 사람에게 전달될 때 정보가 함께 퍼질 수 있습니다. 접수 번호와 회신 예정 경로만 담는 편이 안전합니다.

오류가 난 뒤 작성한 내용이 모두 사라지는 것도 문제입니다. 처음부터 다시 쓰다 지친 사용자가 대충 제출하거나 같은 내용을 여러 번 보내게 되기 때문입니다. 문의 양식 오류 문구를 고칠 때는 내용 유지 방식도 함께 검토합니다.

입력 내용을 남겨 두더라도 민감한 자유 입력 칸은 예외로 둘지, 일정 시간이 지나면 자동으로 지울지 정해 둘 수 있습니다. 어떤 방식을 고르든 사용자가 화면에서 그 사실을 알 수 있게 짧게 안내하면, 다시 써야 하는 이유를 납득하기 쉽습니다.

## 전송 상태를 구분해서 알려 줍니다

사용자가 가장 헷갈리는 순간은 전송이 실패했는지, 접수는 됐는데 확인 메시지만 늦는지 알 수 없을 때입니다. 이 두 상태를 화면에서 분명히 구분해 알려 주면 같은 문의를 여러 번 보내는 일이 줄어듭니다.

중복으로 접수된 문의가 접수 담당자에게 여러 건 쌓이지 않도록 처리 방식을 정해 두고, 사용자가 자신의 문의 상태를 확인할 수 있는 방법이 있다면 함께 안내합니다.

전송 버튼을 누른 직후 화면이 멈춘 것처럼 보이면 사용자는 버튼을 여러 번 누르게 됩니다. 처리 중이라는 표시를 보여 주고, 처리가 끝나면 접수 완료 화면으로 분명히 넘어가게 하면 중복 제출을 줄일 수 있습니다. 완료 화면에는 문의 내용을 다시 띄우지 않고 접수 사실과 회신 경로만 보여 줍니다.

## 실제 정보 대신 시험 자료로 점검합니다

점검할 때는 빈칸으로 제출하기, 잘못된 연락처 넣기, 첨부 파일 올리기 실패, 정상 제출하기를 각각 시험합니다. 이때 실제 환자의 정보는 쓰지 않고 시험용 자료를 사용하며, 점검이 끝나면 시험 자료를 삭제합니다.

입력 내용을 임시로 저장하는 기능이 있다면 뒤로 가기를 눌렀을 때나 공용 기기에서 다른 사람이 접속했을 때 이전 내용이 보이지 않는지 확인합니다. 재입력의 부담과 개인 정보 보호 사이에서 저장 범위와 세션 종료 방식을 정합니다.

문의 양식 오류 문구를 정비하는 일은 작은 화면 수정처럼 보이지만, 방문자가 안심하고 연락할 수 있는 환경을 만드는 일입니다. 정기 점검 목록에 문의 양식 오류 문구와 자동 회신 내용을 함께 넣어 두면 양식을 바꿀 때마다 같은 기준으로 확인할 수 있습니다.
