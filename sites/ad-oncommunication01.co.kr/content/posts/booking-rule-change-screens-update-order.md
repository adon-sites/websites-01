## 바뀐 조건은 한 곳만 고치면 끝나지 않습니다

예약 가능 시간, 적용 대상, 준비 서류처럼 이용자의 결정을 바꾸는 내용이 달라졌을 때 담당자는 공지 한 건을 올리고 마무리하기 쉽습니다. 그런데 이용자는 공지부터 읽지 않습니다. 검색 결과에서 상세 안내로 들어오거나, 예전에 저장해 둔 링크를 열거나, 예약 화면에서 곧바로 시작하는 경우가 훨씬 많습니다. 그래서 변경 작업은 공지 작성이 아니라 이용자가 거치는 화면의 순서를 따라 점검하는 일에서 시작해야 합니다.

공지만 최신이고 예약 화면은 예전 기준 그대로라면, 이력 문구를 아무리 길게 붙여도 혼란은 줄지 않습니다. 이용자는 가장 행동에 가까운 화면의 내용을 믿기 때문입니다.

## 먼저 변경의 무게를 나눕니다

모든 수정을 같은 방식으로 알릴 필요는 없습니다. 오탈자 교정이나 문장 다듬기는 내부 기록으로 남기면 충분합니다. 반면 예약 가능 요일, 접수 마감 시점, 적용 대상처럼 이용자가 신청 여부를 판단하는 데 쓰는 정보라면 현재 안내에서 새 기준과 적용 시작일을 바로 찾을 수 있어야 합니다.

분류 기준은 간단합니다. 이 내용을 몰랐을 때 이용자가 헛걸음을 하거나 신청을 다시 해야 하는가를 묻습니다. 그렇다면 무게가 큰 변경이고, 해당 안내 가까이에 현재 상태를 드러내야 합니다.

## 현재 상태는 행동 버튼 가까이에, 이력은 한 걸음 뒤에

상세 안내의 관련 문단에는 확인된 적용 시점을 짧게 적습니다. 날짜와 조건은 반드시 담당 자료와 대조한 뒤에 씁니다. 자세한 변경 경위는 같은 화면에 길게 풀기보다 이력 페이지로 연결하는 편이 읽기 좋습니다. 현재 기준을 먼저 보여 주고, 궁금한 사람만 이전 기준과 바뀐 이유를 열어 보게 하는 구조입니다.

모든 문단 옆에 긴 기록을 붙이면 본문이 읽히지 않고, 사이트 맨 아래 기록실에만 두면 현재 페이지를 읽는 사람은 변화 자체를 알 수 없습니다. 두 극단 사이에서 현재 상태 한 줄과 이력 링크 하나가 가장 무난한 균형입니다.

## 오래된 입구도 함께 닫아 둡니다

검색 결과나 목록 카드에서 지난 공지로 직접 들어오는 사람이 있습니다. 이런 글에는 종료되었거나 이전 기준이라는 표시를 분명히 하고 현재 안내로 가는 링크를 둡니다. 주소가 바뀌었다면 이전 링크가 새 주소로 이동하는지 직접 열어 봅니다.

같은 조건이 여러 화면에 반복되는 점도 놓치기 쉽습니다. 예약 확인 문자, 자동 응답 메시지, 자주 묻는 질문, 안내 이미지에 예전 시간이 남아 있지 않은지 한 번에 훑어야 합니다. 한 페이지만 고치고 다른 곳에 예전 값이 남으면 이용자는 서로 다른 답을 받게 됩니다.

## 휴대전화 화면에서 읽히는지 확인합니다

변경 사항은 모바일에서 특히 쉽게 묻힙니다. 현재 상태와 적용 시점이 예약 버튼보다 한참 아래에 있으면 눌러야 할 때 보이지 않습니다. 변경 전후를 색으로만 구분하지 말고 이전과 현재라는 말을 텍스트로도 적어 두면 색을 구별하기 어려운 이용자나 화면 읽기 기능을 쓰는 이용자도 순서를 이해할 수 있습니다.

긴 이력을 접힌 영역에 넣더라도 현재의 핵심 조건까지 함께 숨기면 안 됩니다. 접는 것은 과거 기록이고, 펼쳐 두는 것은 지금 적용되는 기준이어야 합니다.

## 바로 쓰는 변경 점검 질문

변경 작업을 마치기 전에 몇 가지 질문으로 확인하면 누락을 줄일 수 있습니다. 새 기준과 적용 시작일이 현재 안내에 적혀 있는가, 예전 기준이 남은 화면은 없는가, 지난 공지에서 현재 안내로 가는 길이 있는가, 안내를 보고 예약한 사람이 다른 조건을 만나지 않는가를 차례로 묻습니다. 마지막으로 직접 이용자가 되어 검색 결과에서 예약 화면까지 따라가 봅니다.

이 점검은 변경이 있을 때마다 새로 만들기보다 체크 항목으로 정해 두면 담당자가 바뀌어도 같은 수준으로 이어집니다. 변경 후 며칠 동안 들어온 문의에서 예전 기준을 묻는 말이 보인다면 놓친 화면이 있다는 신호이므로 그 화면을 먼저 찾아봅니다. 문의 내용은 이름이나 연락처 없이 유형만 기록해도 충분합니다.

## 내부 기록은 이렇게 남깁니다

수정 담당자는 이전 문구, 현재 문구, 근거 자료, 영향을 받는 화면 목록, 확인한 날짜를 내부 문서에 남깁니다. 다음에 같은 조건이 바뀌어도 어디를 열어 봐야 하는지 바로 알 수 있습니다. 이용자에게는 기록 전체가 아니라 지금 어떤 기준을 따르면 되는지만 명료하게 전합니다.

이력을 어디에 두느냐는 기록을 얼마나 많이 보여 주느냐의 문제가 아닙니다. 바뀐 정보가 이용자가 실제로 결정을 내리는 순간에 닿도록 하는 편집상의 선택입니다. 운영 방식과 화면 구성은 사이트마다 다르므로, 위 순서를 출발점으로 삼아 자신의 안내에 맞게 조정하세요.
