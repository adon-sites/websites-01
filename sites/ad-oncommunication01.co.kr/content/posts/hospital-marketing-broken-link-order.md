## 깨진 링크는 모두 같은 순서로 고쳐야 하나요?

그렇지 않습니다. 지도와 예약, 연락 경로가 잘못되면 방문이 어긋나지만, 지난 행사 사진의 외부 주소가 끊긴 문제는 급한 정도가 다릅니다. 병원마케팅 페이지를 운영한다면 이용자의 행동에 바로 영향을 주는 링크를 앞에 둡니다.

우선순위를 정해 두면 운영 중인 화면을 안정적으로 확인할 수 있습니다. 모든 항목을 같은 비중으로 다루면 정작 중요한 링크가 뒤로 밀립니다.

링크 오류는 눈에 띄는 곳보다 오래 방치된 곳에서 더 자주 발견됩니다. 첫 화면은 문제없이 열려도 서비스 소개 깊은 곳의 페이지에서 끊긴 주소가 나올 수 있으므로 메뉴를 따라 내려가며 확인합니다. 발견한 순서가 아니라 이용자가 영향을 받는 정도로 줄을 세워야 합니다.

## 수정 전에 어떤 목록을 만들어야 하나요?

현재 공개된 화면을 기준으로 목록을 만듭니다. 오류가 난 출발 페이지, 링크 문구, 도착 화면을 적고 상태를 나눕니다.

[표] 링크 상태 분류표
| 상태 | 의미 | 먼저 할 일 |
| --- | --- | --- |
| 삭제됨 | 도착 주소가 사라짐 | 새 주소 확인 또는 링크 제거 |
| 다른 곳으로 이동 | 관련 없는 페이지가 열림 | 즉시 교체 |
| 로그인 필요 | 로그인 뒤에만 보임 | 공개 여부 확인 |
| 정상 | 의도한 화면이 열림 | 확인 날짜 기록 |

잘못된 사업장 주소나 운영시간이 표시되고 있다면 공식 정보와 대조해 가장 먼저 고칩니다.

목록에는 담당자와 처리 예정일 칸도 만들어 두면 좋습니다. 누가 어떤 링크를 맡았는지 분명해야 수정이 중간에 멈추지 않고, 다음 점검 때 같은 오류를 다시 찾는 시간도 줄어듭니다.

## 콘텐츠 링크는 무엇을 보고 바꾸나요?

메뉴 안내, 서비스 설명, 제휴 안내처럼 변경 가능성이 높은 자료는 새 페이지가 같은 조건을 보여 주는지 읽어 봐야 합니다. 주소만 새것으로 바꾸고 과거 조건을 그대로 두면 지난 안내를 현재 안내로 오해하게 만듭니다.

이미지 링크를 교체할 때에는 사진의 사용 권한과 현재 모습이 맞는지도 확인합니다. 병원마케팅 자료에서는 오래된 사진이 그대로 남는 경우가 잦습니다.

예약이나 상담 신청처럼 외부 서비스로 이동하는 버튼은 실제로 눌러서 접수 화면까지 열리는지 확인합니다. 주소가 열리기만 해도 안내 문구와 조건이 달라져 있다면 이용자는 잘못된 기대를 안고 신청하게 됩니다.

## 수정은 어느 범위씩 나누어 진행하나요?

작은 범위씩 고치면 문제가 생겼을 때 원인을 찾기 쉽습니다. 한 페이지의 주요 경로를 고친 뒤 컴퓨터와 스마트폰에서 실제로 눌러 봅니다.

[표] 수정 기록에 남길 항목
| 항목 | 기록 내용 |
| --- | --- |
| 수정 전 화면 | 기존 주소와 문구 |
| 수정 후 주소 | 새로 연결한 주소 |
| 확인 날짜 | 직접 열어 본 날 |
| 복구 자료 | 이전 안내로 돌아갈 수 있는 자료 |

여러 주소와 본문을 동시에 바꾸고 문제가 생기면 어느 변경이 원인인지 가리기 어렵습니다.

수정 범위를 나눌 때에는 메뉴 하나, 서비스 소개 한 편처럼 확인하기 쉬운 단위로 정합니다. 단위가 작으면 되돌려야 할 때에도 어디까지 돌아가면 되는지가 분명해서 운영 중인 안내를 오래 비워 두지 않아도 됩니다.

## 수정이 끝나면 무엇을 더 확인하나요?

같은 오류 주소가 다른 글에도 남아 있는지 검색합니다. 문의에서 여전히 잘못된 위치나 조건을 묻는다면 검색 결과 미리보기나 외부 채널에 옛 정보가 남아 있을 수 있습니다.

우선순위가 낮은 항목도 방치하지 않고 담당과 목표 날짜를 남기며, 수정이 끝날 때마다 공개 페이지에서 확인합니다. 외부 예약 업체가 주소를 다시 바꿀 때를 대비해 연락 경로도 정해 둡니다.

## 자주 묻는 질문

### 링크가 많을 때 어디부터 확인해야 하나요?

지도, 예약, 연락 경로처럼 방문과 직결되는 링크부터 확인합니다. 병원마케팅 자료에서는 그 뒤에 소개 글과 이미지 링크를 점검하면 됩니다.

### 링크를 한 번에 모두 바꿔도 되나요?

권하지 않습니다. 작은 범위로 나누어 바꾸고 확인해야 문제가 생겼을 때 원인을 추적할 수 있습니다.

### 수정 기록에는 무엇을 남기나요?

수정 전 화면, 새 주소, 확인 날짜를 남깁니다. 필요하면 이전 안내로 돌아갈 수 있는 자료도 보관합니다.

### 로그인 뒤에만 열리는 링크는 어떻게 하나요?

이용자가 로그인 없이 볼 수 있어야 하는 자료인지 먼저 판단합니다. 공개가 필요 없다면 링크를 정리합니다.

### 점검이 끝난 뒤에도 해야 할 일이 있나요?

같은 주소가 다른 글에 남아 있는지 검색하고, 문의에서 옛 정보가 반복되는지 살핍니다. 병원마케팅 채널마다 남은 정보가 없는지도 확인합니다.

### 우선순위가 낮은 오류는 그냥 둬도 되나요?

방치하지 않습니다. 담당자와 목표 날짜를 남기고 수정이 끝날 때마다 공개 페이지에서 확인합니다.
