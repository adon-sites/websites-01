# 대표 가이드 이미지와 공개 설정

## 적용

- 메인 대표 카드 6개와 ItemList 순서를 content/carousel.json 하나로 관리합니다.
- 각 항목은 실제 원고 한 편으로 연결합니다. 제목은 원고에서, 이미지와 대체 텍스트는 카드 목록에서 읽습니다.
- ItemList는 메인 head에 한 번만 생성하고 position 1–6, 절대 URL, 서로 다른 원본 이미지 URL을 출력합니다.
- 대표 6편은 연결된 상세 원고에서도 같은 이미지를 보여 줍니다. 그 외 900편과 이후 추가하는 일반 글의 기본값은 이미지 없음입니다.
- 글 목록은 모든 페이지가 제목·설명으로 구성됩니다. 공통 썸네일이나 기본 대체 사진을 넣지 않습니다.
- 게시 날짜는 실제 공개 시각이 확정됐을 때만 출력합니다. 검토용 원고를 과거 날짜로 소급하지 않습니다.

## 도메인 연결 후 실행할 설정

현재 검토용 주소의 소유자 전용 공개 범위를 유지하며 검색 차단 상태입니다. 도메인이 정해지면 도메인 소유 계정에서 DNS 연결과 HTTPS를 확인한 뒤 content/company.json의 origin, customDomain, 실제 publishedAt, searchIndexing을 함께 설정하고 재생성합니다. hosting의 공개 범위도 공개 사이트에 맞게 전환해야 합니다.

공개 후 canonical·og:url·ItemList의 글/이미지 URL·사이트맵·RSS가 같은 도메인을 사용하는지, 이미지와 원고 주소가 인증 없이 열리는지 확인합니다. 소유자의 실제 네이버 사이트 확인 값을 받은 다음에만 넣고 사이트맵과 RSS를 제출합니다. 저장한 설정만으로 실제 수집이나 검색 노출이 확인됐다고 기록하지 않습니다.

## 공식 기준

네이버 [캐러셀 구조화 데이터 안내](https://searchadvisor.naver.com/guide/structured-data-carousel)에 맞춰 보이는 항목과 구조화 데이터의 제목·주소·이미지를 일치시킵니다. 네이버는 구조화 데이터를 검색 결과 구성의 참고 정보로 사용하므로 올바른 설정과 실제 노출은 별도로 확인합니다. 의미 정의는 [Schema.org ItemList](https://schema.org/ItemList)를 참고했습니다.
