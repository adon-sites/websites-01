## 페이지 수보다 먼저 볼 것

통합검색에서 사업을 알리고 싶을 때 가장 먼저 떠오르는 방법은 페이지를 많이 만드는 것입니다. 하지만 검색한 사람이 도착한 곳에서 원하는 답을 찾지 못하면 페이지가 늘어도 이용으로 이어지지 않습니다. 그래서 작업에 앞서 각 페이지가 어떤 질문을 해결하는 곳인지 적어 보는 과정이 필요합니다.

첫 화면에 회사 소개와 서비스 설명이 한꺼번에 섞여 있거나 모든 메뉴가 비슷한 제목을 쓰고 있다면, 방문자는 도착해도 길을 잃습니다. 상위 노출을 내세우는 광고 문구를 검토하기 전에 사이트 자체의 정보 구조를 점검하는 이유가 여기에 있습니다.

## 대표 페이지와 서비스 페이지의 역할

대표 페이지에는 사업의 정확한 명칭과 제공하는 서비스의 범위, 공식 연락 경로를 분명히 적습니다. 서비스별 페이지에서는 대상이 누구인지, 어디까지 진행하는지, 문의하기 전에 확인할 조건이 무엇인지를 나누어 설명합니다.

비슷한 서비스를 지역 이름만 바꾸어 되풀이해서 쓰면 이용자가 얻는 차이가 없습니다. 지역 페이지가 꼭 필요하다면 실제 지점이나 서비스 가능 범위에서 다른 안내가 있어야 하고, 그 차이가 본문에 분명하게 담겨야 합니다.

## 기술 점검은 사람의 이용과 이어집니다

기술적인 점검은 검색 엔진만을 위한 일이 아닙니다. 모바일에서 메뉴와 연락 버튼이 제대로 작동하는지, 본문이 화면에서 잘 읽히는지, 내부 링크가 알맞은 페이지로 이어지는지를 직접 확인해 보면 이용자가 겪는 불편이 곧 드러납니다.

제목과 설명 문구는 도착한 페이지의 실제 내용과 맞아야 합니다. 오래된 주소가 남아 있거나 삭제한 페이지로 이어지는 링크가 있다면 경로를 바로잡고, 어떤 주소를 고쳤는지 기록해 둡니다.

## 검색 최적화라는 말을 정확하게 쓰기

검색 최적화는 검색 시스템이 사이트에 접근하고 이해하기 쉽도록 정리하는 작업이고, 질문에 바로 답하는 구성은 이용자의 이해를 돕는 작업입니다. 두 가지를 함께 하더라도 특정 순위나 노출 기간을 확정해 말할 수는 없습니다.

외부 업체에는 어떤 페이지를 수정할지, 기존 글과 중복되는지 어떻게 판단하는지, 수정 전후의 측정 범위가 무엇인지를 물어보세요. 검색 결과의 변화는 경쟁과 검색 환경에서 영향을 받으므로 한 가지 수정만으로 원인을 단정하지 않는 태도가 필요합니다.

## 여러 생활권을 겨냥할 때와 전문 업종의 경우

여러 동네의 고객을 대상으로 한다면 실제 사업장 주소와 서비스 가능 범위를 기준으로 표현을 고릅니다. 가본 적 없는 동네의 사례를 지어내거나 이동 시간을 단정하는 문장은 넣지 않습니다.

법률이나 의료처럼 광고 기준이 별도로 있는 업종은 전문가의 승인 절차를 거쳐야 합니다. 이런 업종의 글은 일반 정보와 개별 상담이 필요한 부분을 구분해 쓰고, 개인의 상황은 상담에서 확인하도록 안내합니다.

## 기록하는 습관이 개선을 이끕니다

운영자는 색인 상태와 방문, 문의 내용을 구분해서 기록합니다. 같은 질문을 다루는 페이지를 새로 늘리기 전에는 기존 문서를 개선할 수 있는지 먼저 살펴봅니다. 방문이 늘지 않는다고 곧바로 글 수를 늘리기보다 문의에서 반복되는 질문을 읽고 해당 페이지의 첫 문단을 고치는 편이 효과를 확인하기 쉽습니다.

검색에 잘 보이는 사이트는 검색어를 억지로 덧붙인 사이트가 아니라, 방문자에게 정확한 길과 답을 제시하는 사이트에서 출발합니다. 어떤 결과가 나타날지는 사이트와 환경에 따라 다를 수 있습니다.

작업 범위를 정할 때는 우선순위를 두는 것도 방법입니다. 방문이 가장 많은 페이지, 문의가 가장 많이 시작되는 페이지, 그리고 가장 오래된 페이지 세 곳을 먼저 살펴보세요. 이 세 곳만 정리해도 구조의 약점이 어디에 있는지 대부분 드러납니다.

점검 결과는 담당자가 바뀌어도 읽을 수 있도록 짧은 문장으로 남깁니다. 어떤 페이지를 왜 고쳤는지, 고치기 전과 후의 화면이 어떻게 달랐는지를 적어 두면 이후 외부 업체와 이야기할 때도 기준 자료가 됩니다.

마지막으로, 점검을 끝낸 뒤에는 방문자의 입장에서 처음부터 끝까지 한 번 따라가 보세요. 검색 결과에서 페이지로 들어가 필요한 정보를 찾고 연락 버튼을 눌러 보는 데 몇 번의 이동이 필요했는지 세어 보면 구조의 복잡함이 숫자로 드러납니다.
