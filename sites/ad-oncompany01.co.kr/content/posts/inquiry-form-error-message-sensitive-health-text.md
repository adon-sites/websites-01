## 오류 화면도 방문자의 정보를 다루는 안내입니다

병원 홈페이지의 문의 양식은 보통 이름과 연락처, 방문을 원하는 시간, 간단한 증상 설명을 받습니다. 입력이 잘못되면 많은 양식이 사용자가 적은 문장을 그대로 오류 화면에 다시 보여 줍니다. 편리해 보이지만 건강 상태나 검사 결과를 적은 사람에게는 부담이 될 수 있습니다. 가족이 함께 쓰는 컴퓨터, 사무실의 공용 기기, 화면을 찍어 두는 습관 때문에 개인적인 내용이 다른 사람에게 보일 수 있기 때문입니다.

그래서 오류 안내는 "어느 칸을 어떻게 고치면 되는지"만 알려 주는 것이 기본입니다. 정상적으로 제출된 화면만 조심하면 된다고 생각하기 쉽지만, 실패한 화면과 자동으로 나가는 메일이나 문자도 같은 기준으로 살펴야 합니다. 이 글에서는 문의 양식을 운영하는 병원 담당자와 양식을 이용하는 환자가 각각 무엇을 확인하면 좋은지 차례로 정리합니다.

## 받는 항목부터 줄이면 오류도 줄어듭니다

오류 문구를 고치기 전에 먼저 이 양식이 왜 이 정보를 받는지 되짚어 봅니다. 예약 가능한 시간을 묻는 양식인데 긴 증상 설명을 필수 칸으로 두었다면 문구를 다듬는 것보다 수집 항목을 줄이는 쪽이 더 근본적인 해결입니다. 받는 정보가 적을수록 잘못 노출될 내용도 줄어듭니다.

자유 입력칸에는 안내 문장을 함께 둡니다. 예를 들어 "상세한 진단명이나 검사 수치는 이 칸에 적지 않으셔도 됩니다. 진료 때 직접 말씀해 주세요"처럼 쓰면 방문자가 스스로 범위를 조절할 수 있습니다. 개별 판단이 필요한 질문은 공개 게시판이 아니라 전화나 방문 상담 같은 적절한 경로로 이어 줍니다. 온라인 양식은 진료 판단을 대신하지 않는다는 점도 한 줄 넣어 두면 좋습니다.

## 오류 메시지는 고칠 곳만 알려 줍니다

좋은 오류 메시지는 해당 항목 가까이에 짧게 나타납니다. "전화번호 형식을 확인해 주세요"처럼 무엇을 고쳐야 하는지만 적고, 사용자가 입력한 문장 전체를 제목이나 안내 문구에 복사하지 않습니다. 화면 상단에 붉은 글씨로 입력 내용을 길게 되풀이하는 방식은 피하는 편이 안전합니다.

이메일이나 문자로 나가는 자동 회신도 같은 원칙을 적용합니다. "문의가 접수되었습니다"라는 사실과 접수 번호, 답변까지 걸릴 수 있는 일반적인 안내만 담고, 증상 설명을 본문에 그대로 인용하지 않습니다. 받는 사람의 메일함이 다른 사람과 공유되는 경우도 있기 때문입니다.

한 가지 더 살펴볼 것은 실패한 뒤의 동작입니다. 오류가 난 다음 작성한 내용이 전부 사라지면 사용자는 같은 내용을 다시 쓰다가 더 많은 정보를 적거나 잘못된 내용으로 제출하기도 합니다. 반대로 내용을 오래 남겨 두면 공용 기기에서 문제가 됩니다. 두 요구 사이에서 어디까지 임시로 유지할지는 병원이 정해 두어야 합니다.

## 접수 상태를 구분하고 중복 제출을 막습니다

"전송에 실패했다"와 "접수는 되었지만 확인 문자가 늦는다"는 서로 다른 상황입니다. 두 경우를 같은 문구로 안내하면 사용자는 불안해서 여러 번 제출하게 되고, 병원 접수 담당자에게는 같은 문의가 여러 건 쌓입니다. 화면에서 현재 상태를 구분해 알려 주고, 이미 접수된 문의는 중복으로 처리되도록 만들어 두면 양쪽 모두 편해집니다.

사용자가 자신의 신청 상태를 다시 확인할 방법도 있으면 좋습니다. 접수 번호와 확인 방법을 안내하고, 일정 시간이 지나도 연락이 없을 때 전화로 확인할 수 있는 번호를 함께 적어 둡니다. 전화 연결이 가능한 시간은 현재 병원의 진료시간 안내와 같은 내용이어야 합니다.

## 점검할 때는 가짜 정보로 시험합니다

양식을 점검할 때는 몇 가지 상황을 각각 시험합니다. 필수 칸을 비웠을 때, 연락처 형식이 틀렸을 때, 첨부 파일이 실패했을 때, 정상적으로 제출했을 때입니다. 각 상황에서 화면과 자동 회신에 어떤 문장이 나타나는지 직접 읽어 봅니다.

시험에는 실제 환자의 정보를 쓰지 않고 가상으로 만든 자료를 사용합니다. 시험이 끝난 뒤에는 접수함과 임시 파일에 남은 시험 자료를 삭제합니다. 개발자가 문제를 찾기 위해 남기는 오류 기록에도 사용자가 쓴 건강 내용 전체가 복사되는지 확인하고, 문제 원인을 찾는 데 필요한 상태 정보와 개인의 상담 내용을 분리해서 기록할 수 있어야 합니다.

## 이용하는 분이 스스로 할 수 있는 확인

양식을 이용하는 입장에서도 몇 가지를 기억해 두면 좋습니다. 공용 컴퓨터에서 문의를 보냈다면 제출 뒤 창을 닫고, 브라우저의 뒤로 가기로 이전 입력 화면이 다시 열리지 않는지 확인합니다. 증상이나 검사 결과를 자세히 적어야 하는지 망설여진다면, 양식에는 방문에 필요한 최소한만 적고 나머지는 진료 시간에 의료진에게 직접 설명해도 됩니다.

오류가 반복되면 같은 내용을 여러 번 제출하기보다 병원 안내에 적힌 전화번호로 접수 여부를 먼저 확인합니다. 이 글의 내용은 일반적인 확인 항목이며, 병원마다 양식의 구성과 운영 방식은 다릅니다. 구체적인 정보 처리 방식은 해당 병원의 개인정보 안내와 상담을 통해 확인하는 것이 가장 정확합니다.
