플레이스 상세 정보, 홈페이지 하단과 위치 안내, 예약 화면, 최근 공지를 나란히 열어 상호·주소·층수·요일별 시간·주차 조건을 확인합니다. 차이가 있으면 임의로 한쪽을 복사하지 말고 현장 담당자에게 현재 값을 확정받습니다. 수정한 화면과 날짜를 기록하고, 임시 변경에는 적용 종료 시점을 함께 남기세요. 지역명을 반복하는 문구는 정확한 방문 정보를 대신할 수 없습니다.
## 재문의와 오래된 연결로 주기를 조정합니다
점검 뒤에도 길 찾기나 영업시간 질문이 반복되면 정보 위치와 표현을 다시 봅니다. 기한이 지난 공지나 깨진 주소가 자주 발견되는 구간은 확인 간격을 줄이고, 오랫동안 변화가 없는 항목은 표본 점검으로 조정할 수 있습니다. 순위가 잠시 움직였다는 이유로 동기화 작업의 옳고 그름을 단정하지 마세요. 수정일과 다음 확인일을 함께 남기는 습관이 최신 방문 정보를 장기간 유지하는 기준이 됩니다.
## ‘중요도와 변경 빈도로 간격을 나눕니다’를 실제 작업 단위로 바꾸기
‘플레이스와 홈페이지 정보를 오래 맞춰 두는 점검 주기’의 내용을 실행하려면 ‘중요도와 변경 빈도로 간격을 나눕니다’, ‘같은 날 여러 화면을 대조합니다’, ‘재문의와 오래된 연결로 주기를 조정합니다’를 한 번에 처리할 항목으로 묶지 않는 편이 좋습니다. 작업표에는 ‘중요도와 변경 빈도로 간격을 나눕니다’의 현재 상태, ‘같은 날 여러 화면을 대조합니다’에 필요한 자료, ‘재문의와 오래된 연결로 주기를 조정합니다’를 확인할 담당자와 날짜를 각각 나눠 적습니다. 〈행사 문구나 일시 공지는 종료일에 맞춰 별도 회수 일정을 잡으세요〉 내용을 검토표로 옮기면, 상태 표시는 유지·수정·추가 확인처럼 고정하면 같은 문서를 보는 사람이 진행 정도를 다르게 해석하는 일을 줄일 수 있습니다. 이때 제목을 다듬는 일과 사실을 확인하는 일을 별도 칸에 두어야 ‘중요도와 변경 빈도로 간격을 나눕니다’의 표현만 바뀌고 ‘같은 날 여러 화면을 대조합니다’의 실제 조건은 그대로 남는 상황을 발견할 수 있습니다.
## ‘같은 날 여러 화면을 대조합니다’의 이전 버전을 다시 찾을 수 있게 보관하기
‘같은 날 여러 화면을 대조합니다’가 수정될 때 이전 파일을 덮어쓰기만 하면 ‘플레이스와 홈페이지 정보를 오래 맞춰 두는 점검 주기’의 설명이 왜 달라졌는지 확인하기 어렵습니다. 파일명이나 관리표에 수정 날짜와 버전, 변경한 사람을 남기고 ‘중요도와 변경 빈도로 간격을 나눕니다’의 이전 문장과 새 문장을 비교할 수 있게 보관합니다. 〈행사 문구나 일시 공지는 종료일에 맞춰 별도 회수 일정을 잡으세요〉 내용을 검토표로 옮기면, 공개할 필요가 없는 내부 검토본은 검색 결과에 노출되는 위치와 분리하고, 실제 기준으로 쓰는 문서에는 현재 상태를 분명히 표시합니다. ‘재문의와 오래된 연결로 주기를 조정합니다’에서 과거 안내를 인용해야 한다면 당시 기준임을 밝히고 지금 적용되는 정보로 이동할 경로를 함께 제공해야 버전 차이가 오해로 이어지지 않습니다.
## ‘같은 날 여러 화면을 대조합니다’의 결과를 해석하는 기준
‘플레이스와 홈페이지 정보를 오래 맞춰 두는 점검 주기’를 게시했다는 사실, ‘같은 날 여러 화면을 대조합니다’가 화면에 노출됐다는 사실, 실제 문의나 행동이 생겼다는 사실은 서로 다른 단계입니다. 관찰 기록에는 확인한 주소와 시점, 사용한 기기나 경로, ‘중요도와 변경 빈도로 간격을 나눕니다’에서 ‘재문의와 오래된 연결로 주기를 조정합니다’까지 실제로 이동했는지를 적습니다. 한 번의 화면 확인만으로 ‘같은 날 여러 화면을 대조합니다’의 성과를 확정하지 않고 비교 기간과 변경 내용을 같이 봅니다. 문의가 늘거나 줄었을 때도 곧바로 한 문장 때문이라고 결론짓지 말고 ‘중요도와 변경 빈도로 간격을 나눕니다’의 내용 변경, ‘재문의와 오래된 연결로 주기를 조정합니다’의 연결 상태, 운영 일정처럼 함께 달라진 조건을 구분합니다.
## ‘중요도와 변경 빈도로 간격을 나눕니다’만 고쳤을 때 생기는 빈틈
예를 들어 ‘중요도와 변경 빈도로 간격을 나눕니다’의 문장을 최신 기준에 맞게 수정했더라도 ‘같은 날 여러 화면을 대조합니다’의 안내 이미지나 ‘재문의와 오래된 연결로 주기를 조정합니다’의 연결 주소가 예전 상태라면 독자는 서로 다른 답을 받게 됩니다. 이 경우 문장 하나의 완성도보다 ‘플레이스와 홈페이지 정보를 오래 맞춰 두는 점검 주기’와 관련된 노출 위치를 먼저 목록으로 만드는 편이 효율적입니다. 〈행사 문구나 일시 공지는 종료일에 맞춰 별도 회수 일정을 잡으세요〉 내용을 검토표로 옮기면, 본문, 목록 카드, 문의 화면, 지도나 외부 채널 가운데 실제로 같은 정보를 쓰는 위치만 골라 수정 범위를 정합니다. ‘같은 날 여러 화면을 대조합니다’가 공통 기준을 참조하도록 연결하고 ‘재문의와 오래된 연결로 주기를 조정합니다’에 변경 날짜를 남기면 일부 화면만 고쳐 생기는 차이를 다음 점검에서 빠르게 찾을 수 있습니다.

## 작은 화면에서 ‘표현을 정보·비교·행동 의도로 나눕니다’와 ‘발견보다 질문이 끝났는지 확인합니다’를 다시 확인하기
