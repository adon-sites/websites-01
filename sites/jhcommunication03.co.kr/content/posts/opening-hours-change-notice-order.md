## 운영시간을 바꿀 때 가장 먼저 정할 것은 무엇인가요?

변경의 범위입니다. 앞으로 계속 적용되는 정기 운영시간의 변경인지, 특정 날짜에만 해당하는 일시 휴무인지 먼저 구분합니다. 두 경우는 공지의 제목과 게시 기간, 고쳐야 할 화면이 모두 다릅니다.

전화를 받는 시간과 방문 상담이 가능한 시간이 다르다면 각각 따로 적습니다. 예약이 필요한 업무라면 신청을 받을 수 있는 시간과 실제 상담이 확정되는 시간을 혼동하지 않게 나눕니다. 아직 정해지지 않은 일정은 확정된 것처럼 적지 않습니다.

[표] 변경 유형별로 달라지는 안내 방식
| 변경 유형 | 공지에 적을 것 | 고칠 화면 |
| --- | --- | --- |
| 정기 운영시간 변경 | 적용 시작일과 새 시간대 | 공식 사이트, 지도, 예약 양식 전체 |
| 특정일 일시 휴무 | 해당 날짜와 재개 시점 | 공지와 지도의 임시 표시 |
| 전화 응대 시간만 변경 | 전화와 방문 시간을 구분한 표기 | 연락처 안내와 통화 버튼 주변 문구 |

## 공지 문구에는 날짜와 시간을 어떻게 적어야 하나요?

적용 날짜와 시간대를 숫자로 분명히 적습니다. "다음 주부터" 같은 상대적인 표현은 글을 올린 날에는 자연스럽지만, 몇 달 뒤 검색으로 들어온 사람에게는 전혀 다른 뜻이 됩니다. 공지 글은 올린 날보다 훨씬 오래 검색 결과에 남는다는 점을 전제로 씁니다.

오전과 오후가 헷갈리지 않게 표기하고, 점심시간이나 상담이 어려운 시간대도 실제 운영에 맞춰 함께 적습니다. 시간이 달라졌다고 해서 처리하는 업무의 범위가 넓어지는 것은 아니므로, 운영시간 공지에 업무 안내를 덧붙여 오해를 만들지 않습니다.

## 이미 예약한 사람에게는 어떻게 알려야 하나요?

공지를 올리는 것만으로는 닿지 않을 수 있으므로 기존 예약에 영향이 있는지부터 확인합니다. 바뀐 시간대에 잡혀 있던 예약이 있다면 별도의 안내가 필요합니다. 공지 글에도 기존 예약이 그대로 유지되는지, 다시 정해야 하는지를 한 문장으로 밝혀 두면 같은 문의가 줄어듭니다.

연락할 때에는 수신에 동의한 경로와 범위 안에서만 알립니다. 안내에 필요한 것 이상의 개인정보를 꺼내 쓰지 않고, 변경된 시간과 다시 정할 수 있는 방법을 간단히 전합니다. 종합광고대행사가 문자나 알림 발송을 대신하는 경우에도 동의 범위의 확인은 운영 주체가 직접 합니다.

## 여러 채널은 어떤 순서로 고쳐야 하나요?

공식 사이트를 먼저 고칩니다. 기준이 되는 화면이 정해져야 나머지를 대조할 수 있습니다. 그다음 지도와 검색 프로필, 블로그에 남은 지난 안내를 하나씩 맞대어 봅니다.

수정이 끝나면 휴대전화에서 통화 버튼과 예약 버튼을 직접 눌러 새 시간이 반영됐는지 확인합니다. 외부 예약 서비스나 검색 결과는 반영이 늦을 수 있습니다. 그동안에는 현재 기준을 볼 수 있는 공식 경로를 공지에서 안내해 둡니다.

고친 채널과 날짜, 담당자를 기록해 두면 빠진 화면을 찾기 쉽습니다. 종합광고대행사와 채널을 나눠 관리하고 있다면 이 기록표를 함께 쓰는 것이 누락을 줄이는 방법입니다.

[표] 채널별 반영 순서와 확인 방법
| 순서 | 채널 | 확인 방법 |
| --- | --- | --- |
| 첫째 | 공식 사이트 | 운영 안내와 예약 화면의 시간 일치 여부 |
| 둘째 | 지도와 검색 프로필 | 등록된 시간과 임시 표시 대조 |
| 셋째 | 블로그와 지난 공지 | 예전 시간이 적힌 글에 변경 안내 추가 |
| 넷째 | 외부 예약 서비스 | 신청 가능 시간대를 직접 눌러 확인 |

## 변경한 뒤에는 무엇을 살펴봐야 하나요?

예전 시간에 맞춰 들어오는 문의나 방문이 있는지 봅니다. 그런 일이 있다면 어느 화면을 보고 왔는지 물어 남아 있는 지난 안내를 찾아냅니다. 한 사람이 본 화면은 다른 사람도 보고 있을 가능성이 큽니다.

공지를 읽었는데도 같은 질문이 반복된다면 변경 내용이 제목과 첫 문단에 드러나 있는지 다시 봅니다. 운영시간 변경 공지는 글 한 편을 더 발행하는 일이 아니라, 이용자가 어느 화면을 보더라도 같은 현재 시간을 확인하게 만드는 관리입니다.

## 자주 묻는 질문

### 운영시간 변경 공지는 언제 올리는 것이 좋은가요?

변경이 확정된 뒤, 적용일 전에 여유를 두고 올립니다. 확정되지 않은 일정을 먼저 알리면 다시 고쳐야 할 때 혼란이 더 커집니다.

### 일시 휴무도 지도 정보에 반영해야 하나요?

반영하는 편이 좋습니다. 방문을 준비하는 사람은 지도에서 시간을 확인하는 경우가 많아, 공지에만 적어 두면 헛걸음이 생길 수 있습니다.

### 지난 공지 글은 지워야 하나요?

지우기보다 변경되었다는 안내를 덧붙이는 방법이 있습니다. 검색으로 예전 글에 들어온 사람도 현재 시간을 확인할 수 있게 하는 것이 목적입니다.

### 종합광고대행사에 채널 관리를 맡겼다면 수정 요청은 어떻게 해야 하나요?

바뀐 시간과 적용일, 고칠 채널 목록을 한 번에 문서로 전달합니다. 수정이 끝난 뒤에는 화면을 직접 열어 반영 여부를 확인하는 단계를 남겨 둡니다.

### 외부 검색 결과에 예전 시간이 계속 보이면 어떻게 하나요?

반영에 시간이 걸릴 수 있으므로 공식 사이트의 현재 안내를 기준으로 삼도록 알립니다. 수정할 수 있는 프로필이라면 등록 정보를 다시 확인합니다.

### 전화 응대 시간과 방문 상담 시간을 꼭 나눠 적어야 하나요?

두 시간이 다르다면 나눠 적습니다. 하나로 적으면 통화가 되는 시간에 방문 상담도 가능하다고 받아들이는 사람이 생깁니다.
