PDF 분량은 열기 전에 실제 페이지 기준으로 안내합니다

공개 확인일 2026.09.22

PDF를 열기 전 페이지 수를 알 수 없으면 이용자는 읽는 시간이나 인쇄 범위를 예상하기 어렵습니다. 수강 자료 목록에는 파일 이름과 함께 실제 문서 분량을 확인할 수 있는 표시가 필요합니다.

애드온 편집팀

PDF를 열기 전 페이지 수를 알 수 없으면 이용자는 읽는 시간이나 인쇄 범위를 예상하기 어렵습니다. 수강 자료 목록에는 파일 이름과 함께 실제 문서 분량을 확인할 수 있는 표시가 필요합니다.

페이지 수는 표지와 부록을 포함한 전체 수인지 본문만의 수인지 구분합니다. 파일을 교체한 뒤 예전 숫자가 남지 않도록 실제 PDF의 마지막 페이지와 화면 표시를 대조합니다. 스캔된 빈 페이지도 분량에 포함됐는지 확인합니다.

여러 PDF를 한 항목에 제공한다면 각 파일의 페이지 수와 합계를 혼동하지 않게 씁니다. 태블릿 세로 화면에서는 분량 표시가 제목에서 떨어져 다른 파일 정보처럼 보이지 않는지 살핍니다.

페이지가 많다는 이유만으로 자동 분할하지 않습니다. 목차와 내부 링크가 필요한지, 특정 부분만 별도 자료로 제공할 때 맥락이 사라지지 않는지 검토합니다. 숫자를 줄이기 위해 내용이나 조건을 임의로 삭제하지 않습니다.

이용자는 페이지 수와 목차를 보고 전체 읽기, 필요한 구간 확인, 인쇄 여부를 결정할 수 있어야 합니다. 운영자는 발행 전 최종본을 기준으로 분량을 갱신하고, 내용 갱신 기록과 함께 보존합니다. 페이지 수는 품질 점수가 아니라 학습 계획을 돕는 정보입니다.

PDF 내부의 페이지 번호와 뷰어가 보여 주는 전체 장수가 다를 수 있으므로 안내 기준을 정합니다. 표지에 번호가 없더라도 실제 파일 분량에서는 제외되지 않을 수 있음을 확인합니다. 개정으로 페이지가 늘거나 줄면 목차의 번호와 내부 링크도 함께 시험합니다. 특정 장만 인쇄하도록 안내할 때는 실제 페이지와 인쇄 번호가 어긋나지 않는지 살피고, 이용자가 잘못된 범위를 출력하지 않게 설명합니다.
