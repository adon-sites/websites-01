검색어를 준비, 비교, 방문이나 문제 해결의 질문으로 읽어 봅니다. 표현이 달라도 같은 답이 필요하면 한 묶음으로 관리하고, 같은 진료명이 있어도 다른 행동을 요구하면 나눕니다. 개인정보나 개별 건강 상태가 포함된 실제 문의는 공개 원고로 옮기지 않고 일반화된 질문으로 정리합니다. 검색어가 적게 잡혀도 반복 문의가 있는 주제라면 검토할 가치가 있습니다.

기록에서 글의 빈틈을 찾았다면 새 글부터 만들지 말고 기존 페이지를 봅니다. 제목은 준비를 약속하지만 본문이 일반 소개로 끝나지는 않는지, 첫 문단에 대상과 조건이 있는지 확인합니다. 비용 문의가 많다면 포함 범위와 변동 조건이 분명한지도 살핍니다. 진료 내용은 확인 가능한 근거와 일반 정보의 한계를 구분해 작성합니다.

수정표에는 검색 문장, 현재 URL, 바꾼 문장과 확인한 날짜를 연결합니다. 실제 공개 화면에서 제목과 첫 문단, 다음 링크가 같은 질문 흐름을 만드는지 점검합니다. 검색 결과에 반영되는 표현은 즉시 바뀌지 않을 수 있으므로 나중에 다시 확인해야 합니다. 지역명만 다른 여러 글이 같은 답을 반복하면 대표 글의 역할도 재검토합니다.

검색어 기록의 성과는 단어를 많이 수집하는 데서 끝나지 않습니다. 독자가 어떤 질문을 했고 어느 페이지에서 답을 얻지 못했는지를 발견해 문서를 고치는 데 사용해야 합니다. 수치와 실제 문의의 내용을 함께 읽으면 원고의 우선순위도 더 분명해집니다.
