기억과 확인된 기록을 나눠 모은다: 수술·시술 전후와 최근 사진을 날짜·각도별로 정리하고 이전 방법·시기·회복 문제, 라인이 달라지는 상황, 기능 불편, 복용약·질환을 기록한다.

자료가 많아도 “기존 라인은 언제 어떤 조건에서 달라졌으며 현재 원하는 변화와 어떤 차이가 있는가”와 직접 연결되지 않으면 판단을 더 어렵게 할 수 있다. “기존 라인은 언제 어떤 조건에서 달라졌으며 현재 원하는 변화와 어떤 차이가 있는가”의 현재 단계에 필요한 문서와 질문만 앞에 두고 배경 자료는 뒤에서 참고한다. “기존 라인은 언제 어떤 조건에서 달라졌으며 현재 원하는 변화와 어떤 차이가 있는가”에 관한 새 정보를 받으면 기존 결론을 덮어쓰기보다 무엇이 달라졌는지 기록한다.

모은 정보는 “기존 라인은 언제 어떤 조건에서 달라졌으며 현재 원하는 변화와 어떤 차이가 있는가”의 판단 순서에 맞춰 사용한다: 상담에서 현재 구조와 기존 유착·흉터에 대한 평가, 자연유착이라는 제안의 실제 내용과 적합성, 다른 방법, 예상 한계·위험, 회복과 추가 처치 가능성을 확인한다.

다음 정보는 결론의 근거로 삼기 어렵다: 사진을 보정하거나 촬영 조건이 다른 자료를 직접 비교하지 않는다. 특정 기법이 기존 라인을 완전히 없애거나 원하는 라인을 보장한다고 받아들이지 않는다.

최종 결정을 내리기 전에는 “기존 라인은 언제 어떤 조건에서 달라졌으며 현재 원하는 변화와 어떤 차이가 있는가”를 처음 적었을 때와 지금 확보한 답을 비교한다. 설명이 달라졌다면 바뀐 근거와 날짜를 과거 시점·사진 조건·수술 기록·현재 변화·방법·대안·위험을 담은 라인 연표에 추가하고, 결론에 영향을 주지 않은 참고 정보는 별도 칸으로 옮긴다. 다른 검토자도 “기존 라인은 언제 어떤 조건에서 달라졌으며 현재 원하는 변화와 어떤 차이가 있는가”에 관해 확인된 내용과 추가로 물을 부분을 구분할 수 있어야 한다.

정리 결과는 과거 시점·사진 조건·수술 기록·현재 변화·방법·대안·위험을 담은 라인 연표에 남긴다. 과거 시점·사진 조건·수술 기록·현재 변화·방법·대안·위험을 담은 라인 연표에는 “기존 라인은 언제 어떤 조건에서 달라졌으며 현재 원하는 변화와 어떤 차이가 있는가”의 근거가 된 자료, 작성 시점, 확인한 담당자와 다음 확인일을 적는다. 과거 시점·사진 조건·수술 기록·현재 변화·방법·대안·위험을 담은 라인 연표에서 개인 정보가 포함된 원본은 공개용 메모와 분리해 보관한다.

마지막 점검은 다음 기준으로 한다: 자료와 진찰을 바탕으로 기존 상태의 의미, 가능한 변화와 남을 수 있는 문제, 대안과 사후관리 계획을 이해한 뒤 선택을 숙고한다.
