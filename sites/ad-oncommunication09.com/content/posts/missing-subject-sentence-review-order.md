## 어떤 문장부터 점검해야 하나요?

주어가 빠져서 두 가지로 읽히는 문장부터 봅니다. "확인한다"라는 문장이 이용자가 확인한다는 뜻인지 운영자가 확인한다는 뜻인지 알 수 없다면, 독자는 자기 몫이라고 오해하거나 상대 몫이라고 기대하게 됩니다. 이런 문장은 접수 뒤에 연락이 오는지 직접 확인해야 하는지 같은 실제 행동의 차이로 이어지기 때문에 먼저 찾아 고칠 가치가 있습니다.

문법적으로 틀린 문장을 찾는 작업이 아니라 책임이 갈리는 지점을 찾는 작업이라는 점이 중요합니다. 같은 사람이 이어서 하는 동작은 자연스럽게 생략해도 괜찮고, 단계가 바뀌는 곳에서만 주체를 새로 밝혀도 읽기에 충분합니다.

## 절차 문장에서는 무엇을 표시하나요?

신청, 접수, 검토, 승인, 결과 안내 같은 동사를 먼저 표시하고, 각 단계의 주체를 실제 업무 절차와 대조합니다. 두 부서가 나누어 맡는 단계라면 정확한 범위를 확인해야 합니다.

"신청 후 연락"처럼 누가 언제 어떤 채널로 알리는지가 비어 있는 표현은 문법만 고쳐서는 해결되지 않습니다. 사실 자료가 없다면 추측으로 채우지 말고 담당자에게 질문합니다. 정형외과 광고대행사의 원고 검수에서도 병원이 확인해 준 절차만 문장에 담습니다.

| 단계 | 문장에서 확인할 것 | 놓치기 쉬운 부분 |
| --- | --- | --- |
| 신청 | 누가 어떤 방법으로 요청하는지 | 접수와 확정의 구분 |
| 검토 | 누가 어느 기준으로 보는지 | 담당 부서가 둘일 때의 범위 |
| 승인 | 누가 결정하는지 | 조건과 기한 |
| 결과 안내 | 누가 어떤 채널로 알리는지 | 시점과 방법 |

## 초안 작성 지침은 어떻게 고쳐야 하나요?

주어를 일률적으로 반복하라는 지침 대신 단계가 바뀔 때 주체를 새로 밝히라고 적습니다. 이렇게 쓰면 문장이 지나치게 늘어나지 않으면서도 책임이 갈리는 곳이 분명해집니다. 정형외과 광고대행사가 여러 병원의 원고를 한꺼번에 다룰 때도 같은 기준표 하나로 점검을 나눌 수 있습니다.

특히 이용자의 행동에서 시스템의 자동 처리로 바뀌는 부분을 사람이 직접 하는 것처럼 쓰면 기대가 달라집니다. 실제 화면에 나오는 상태 이름과 안내 문장이 서로 일치하는지도 같이 확인해야 합니다.

## 버튼과 자동 메시지는 어떻게 검수하나요?

본문과 따로 검수합니다. "완료"라는 표시가 신청 접수를 말하는지 결과 확정을 말하는지 구분하고, 다음 행동의 주체를 알려 줍니다. 본문만 고치고 문자나 이메일에 이전 문구가 남으면 같은 문의가 반복됩니다.

수정할 화면은 목록으로 만들어 한 번에 확인합니다. 한 곳씩 따로 고치면 일부가 빠지기 쉽고, 빠진 화면에서 이전 표현이 계속 노출됩니다. 목록에는 화면 이름과 확인한 날짜, 확인한 사람을 함께 적어 두면 누락 여부를 나중에 되짚을 수 있습니다.

[표] 수정할 화면 목록의 예
| 화면 | 확인할 문구 | 맞춰야 할 기준 |
| --- | --- | --- |
| 신청 버튼 | 접수인지 확정인지 | 실제 처리 단계 |
| 자동 메시지 | 다음 행동의 주체 | 본문 안내 |
| 문자·이메일 | 예전 문구의 잔존 여부 | 현재 절차 |
| 상태 표시 | 상태 이름의 뜻 | 화면 안내 문장 |

## 모바일 화면과 반복 오류는 어떻게 다루나요?

공간이 짧다는 이유로 "처리 중" 같은 모호한 상태만 남기지 않습니다. 한 줄로 핵심 상태를 밝히고 필요하면 세부 절차로 이어지게 합니다. 문장을 줄이면서 자격이나 기한 같은 조건을 지우지 않도록 주의합니다.

검수 결과에서 같은 오류가 자주 나온다면 기존 템플릿과 초안 예시를 고칩니다. 수정 전후 문장과 실제 업무 주체를 기록해 두면 새로 맡은 작성자도 왜 바뀌었는지 알 수 있습니다. 주어 오류를 막는 일은 문법 검사보다 이용자의 할 일과 운영자의 책임을 나누는 작업에 가깝습니다.

## 자주 묻는 질문

### 모든 문장에 주어를 넣으면 더 안전하지 않나요?

문장이 반복되어 읽기 어려워지고, 정작 책임이 갈리는 곳은 여전히 불분명할 수 있습니다. 단계가 바뀌는 곳만 분명히 밝히는 편이 효과적입니다.

### 정형외과 광고대행사가 절차를 직접 알 수 없을 때는 어떻게 하나요?

병원 담당자에게 누가 무엇을 어떤 채널로 알리는지 질문하고, 확인된 내용만 적습니다. 확정되지 않은 절차를 추측해서 채우면 안내와 현장이 달라집니다.

### 자동 처리와 사람이 하는 일은 어떻게 구분하나요?

시스템이 자동으로 처리하는 단계는 "자동으로" 같은 표현으로 밝히고, 사람이 확인하는 단계는 확인하는 주체를 적습니다. 이용자가 기다려야 하는 단계라면 다음 안내가 오는 방식도 함께 적습니다.

### 모바일에서 문장을 줄일 때 지켜야 할 것은 무엇인가요?

자격이나 기한 같은 조건을 삭제하지 않습니다. 핵심 상태를 한 줄로 쓰고 더 긴 설명은 세부 절차 화면으로 연결합니다.

### 같은 오류가 반복되면 무엇을 고쳐야 하나요?

개별 원고보다 기존 템플릿과 초안 예시를 먼저 고칩니다. 오류가 생기는 틀을 그대로 두면 새 원고에서도 같은 문제가 이어집니다.

### 정형외과 광고대행사 원고 검수 기록은 어떻게 남기나요?

수정 전후 문장과 실제 업무 주체, 확인한 담당자를 함께 적습니다. 기록이 있으면 같은 검토를 다시 하지 않아도 되고 후속 작성자가 기준을 이해하기 쉽습니다.
