## 카드를 누른 순간 생기는 기대

목록의 카드를 눌러 상세 화면으로 이동한 이용자의 머릿속에는 이미 질문이 하나 들어 있습니다. 카드에 적힌 제목이나 요약이 던진 질문입니다. 상세 화면의 첫 부분이 그 질문에 곧바로 답하지 않고 홍보성 문장만 되풀이하면, 이용자는 자신이 잘못 눌렀나 의심하게 됩니다.

설계할 때는 카드가 약속한 내용과 상세 화면의 첫 구역을 나란히 놓고 대조해 보는 습관이 유용합니다. 카드가 기간이나 대상을 언급했다면 상세 화면에서도 같은 항목이 같은 값으로 이어져야 하고, 서로 다른 표현을 쓰고 있다면 하나로 맞춥니다.

## 첫 구역에 놓을 정보의 선택

첫 구역에는 이 항목이 누구에게 해당하는지, 어디까지 제공되는지를 먼저 밝힙니다. 운영 시간이나 신청 방법, 장소처럼 이용자가 결정에 쓰는 값은 확인된 자료에서만 가져옵니다. 예외나 제한 조건은 페이지 아래쪽에 묻어 두지 말고 관련된 답 바로 옆에 둡니다.

아직 근거가 없는 성과 수치나 실제로 제공하지 않는 선택지를 넣어 화면을 채우려는 유혹도 경계해야 합니다. 비어 보이더라도 확인된 사실만 있는 화면이 신뢰를 지켜 줍니다.

## 한 페이지에 모든 것을 넣지 않기

상세 페이지의 임무는 모든 정보를 담는 것이 아닙니다. 처음 보는 사람이 선택 여부를 판단할 최소한의 답을 주고, 더 깊은 설명이나 별도 절차로 가는 길을 분명히 해 주면 됩니다.

목록으로 돌아가 다른 항목과 견주어 볼 수 있는 길도 필요합니다. 페이지 안에서만 오갈 수 있고 상위 범주로 복귀할 수 없는 구조는 여러 항목을 비교하려는 이용자에게 불편을 줍니다. 뒤로 가기에만 기대지 않도록 화면 안에 복귀 경로를 두는 것이 좋습니다.

## 작은 화면에서 직접 확인하기

모바일 기기에서 상세 화면의 첫 부분을 직접 열어 봅니다. 제목이 잘리면서 뜻이 달라지지 않는지, 화면 위쪽의 요소가 핵심 조건을 아래로 밀어내지 않는지, 버튼의 이름이 다음 화면의 내용을 정확히 알려 주는지를 확인합니다. 페이지가 길다면 목차를 눌렀을 때 해당 항목으로 정확히 이동하는지도 시험합니다.

글자 크기를 키웠을 때 안내 문구가 겹치거나 가려지는 문제도 놓치기 쉽습니다. 내용이 있어도 읽을 수 없다면 이용자에게는 없는 정보와 같습니다.

## 갱신 책임과 중복 줄이기

상세 페이지는 여러 경로에서 열립니다. 지난 공지나 검색 결과를 거쳐 들어오는 경우도 있으므로, 날짜가 바뀌는 정보에는 검토 책임자와 확인한 시점을 기록하고 연결된 화면의 값이 서로 맞는지 점검합니다.

같은 문장을 다른 상세 페이지에 복사해 두면 수정할 때 하나를 빠뜨리기 쉽습니다. 공통 조건은 관리하기 쉬운 기준 페이지로 모으고, 항목별 고유 조건만 상세 페이지에서 따로 다루는 편이 안전합니다.

상세 페이지를 점검할 때는 처음 방문한 사람의 눈으로 보는 연습이 필요합니다. 운영자는 내용을 이미 알고 있어서 빠진 설명을 알아채기 어렵습니다. 사이트를 처음 보는 사람에게 상세 화면을 보여 주고 이 항목이 누구를 위한 것인지, 다음에 무엇을 하면 되는지를 말해 달라고 부탁해 보면 부족한 부분이 금방 드러납니다.

이때 나온 의견은 문구를 바꾸는 데서 끝내지 말고 목록 카드의 문구와도 함께 맞춰 봅니다. 상세 화면만 고치고 카드를 그대로 두면 두 화면 사이의 어긋남이 다시 생기기 때문입니다.

버튼과 링크의 이름도 한 번 더 살펴봅니다. 자세히 보기처럼 어디로 가는지 알 수 없는 이름보다 신청 방법 확인, 운영 시간 보기처럼 이동 후의 내용을 예상할 수 있는 이름이 이용자의 망설임을 줄여 줍니다. 이름이 정확하면 상세 페이지 첫 구역의 답과도 자연스럽게 이어집니다.

마지막으로 오류 상황도 고려합니다. 항목이 종료되었거나 정보가 아직 준비되지 않은 상태로 상세 화면에 들어온 이용자에게 빈 화면이나 이전 정보를 보여 주지 않고, 현재 상태와 대안 경로를 짧게 안내하는 문구를 마련해 두면 이탈을 줄일 수 있습니다.

## 발행 뒤에 읽어야 할 신호

발행한 뒤에는 상세 페이지를 읽고도 같은 질문이 문의로 돌아오는지를 살핍니다. 조건이 빠졌는지, 위치가 숨겨졌는지, 표현이 낯선지를 구분해서 고치면 됩니다. 상세 페이지가 제 몫을 한다는 것은 길이가 충분하다는 뜻이 아니라, 목록에서 선택한 사람이 답과 다음 단계를 곧바로 찾을 수 있다는 뜻입니다. 사이트마다 이용 흐름과 관리 체계가 다르므로 위의 점검 항목은 각자의 운영 환경에 맞게 조정해 적용하시기 바랍니다.
