신규 도메인 검토용 사이트. 현재 비공개 및 검색 차단.

## 구성
- 대표 글 6개: 치과소개, 임플란트, 사랑니발치, 충치·신경치료, 의료진, 진료시간·오시는 길.
- 홈페이지 HTML 캐러셀 6개와 head ItemList를 동일 데이터에서 생성.
- 블로그 첫 페이지 6개 대표 글, 주제별 카테고리 URL.
- 모든 상세 글 하단 시흥치과(메인) 키워드 링크 1개. 공식 홈페이지·플레이스는 사이트 하단 방문 링크.
- canonical, OG, Dentist 구조화 데이터. 하위 페이지 ItemList 없음.
- 검색 차단 중 sitemap/RSS 항목 없음. 신규 도메인·소유확인·전체공개 준비 후 활성화.
- 제공 원고의 텍스트 75개는 content/reference에 보관. 첨부 자료의 나머지 1개는 엑셀. 원문을 그대로 공개하지 않음.
- 대표 글 6편과 건강정보 194편으로 총 200편. 기존 건강정보 33편을 재검토·보강하고, 임플란트 41편·사랑니 35편·충치·신경치료 45편·치아관리 40편을 추가. 건강정보 본문은 모두 최소 1,300자이며 이미지 없음. 사용한 원본 파일은 39개, 나머지 36개는 유사 내용 또는 출처 표현 문제로 재사용하지 않음. 일반 의료정보는 글별 공식 근거 URL을 내부 데이터에 기록.
- 자동발행은 시작하지 않음. 신규 도메인을 연결한 뒤 수집 허용 설정 가능.
- 실제 원고의 기준 파일은 content/posts.json, 검수 결과는 content/editorial-audit-200.json·content/review.json·content/editorial-progress.json. content/editorial-queue-200.json은 예전에 만든 목차 초안이므로 글 수나 발행 현황에 사용하지 않음. batch_01.json의 8편은 posts.json에 이미 포함돼 있으며 별도 추가로 세지 않음.
- 사용 X 이미지 제외. 공급 자료만 이미지 사용. 카페 질문글과 의료진 명의 칼럼을 사칭하지 않음.
