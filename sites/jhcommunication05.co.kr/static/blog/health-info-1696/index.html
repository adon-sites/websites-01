품절 옵션 구분 문제는 정상 화면만 봐서는 찾기 어렵다. 출발 장면은 다음과 같다. 재고가 없는 옵션도 구매 가능한 옵션과 같은 모양이라 선택 뒤에야 오류가 나타나는 장면

근거가 닿는 경계를 밝힌다. 비활성화는 색상 차이만으로 전달되지 않으며 조합형 옵션은 앞선 선택에 따라 가능 여부가 바뀐다. 옵션 상태 범례에서 더 강한 주장은 담당자의 확인 자료가 있을 때만 채택한다.

비교 기준을 좁혀 본다. 상태 이름, 조작 가능성, 품절 이유와 재입고 정보가 서로 모순되지 않는지를 확인한다. 품절 옵션 구분에서는 서로 다른 출처의 값을 억지로 한 점수로 합치지 않는다.

확인 담당자는 마우스·키보드·터치로 옵션을 이동하며 품절 값이 선택이나 장바구니 추가를 막는지 본다. 다음 담당자에게는 색상과 크기 조합을 바꿀 때 이전 선택이 유효한지, 품절 해제 뒤 화면이 갱신되는지 살핀다. 옵션 상태 범례에 적용할 원칙: 인계할 때는 결론만 넘기지 않고 근거 위치도 함께 준다.

독자의 다음 행동을 실제로 눌러 본다. 옵션 상태 범례가 설명만 정확하고 이동·연락·복구가 막혀 있다면 작업은 아직 완료되지 않았다.

자료를 해석할 때 한계를 표시한다. 회색만으로 상태를 표현하면 저시력 사용자가 놓칠 수 있고 품절값을 숨기면 전체 선택지를 비교하기 어렵다. 옵션 상태 범례는 개인 판단이 필요한 부분을 적절한 전문가나 담당 절차로 연결한다.

성과 자료와 품질 자료는 분리한다. 품절 옵션 구분의 노출·클릭 변화가 나타나더라도 정보 정확성이나 안전성이 자동으로 증명되는 것은 아니다.

수정 이후의 책임도 정한다. 품절 옵션 구분에서 새 오류가 접수되면 누가 원자료를 확인하고 어느 공개 위치를 먼저 고칠지 연결해 둔다.

한 번에 바꿀 항목을 제한한다. 품절 옵션 구분의 여러 조건을 동시에 수정하면 무엇이 문제를 풀었는지 알 수 없으므로 가장 큰 장애부터 처리한다.

범위 밖 질문에는 다음 목적지를 적는다. 품절 옵션 구분이 모든 문제를 해결하려 들면 중심 질문이 흐려지고 전문 판단이 필요한 경계도 감춰진다.

완료 산출물로 옵션 상태 범례를 선택한다. 가능·선택됨·품절·판매 종료 상태를 범례로 정의하고 실제 조합 화면에 일관되게 적용한다. 옵션 상태 범례에 적용할 원칙: 결과를 확인한 사람과 시각을 적어 후속 작업의 출발점으로 쓴다.
