고객이 “얼마예요?”라고 묻는 순간 바로 하나의 숫자를 말할 수 없는 경우가 있습니다. 같은 소음도 원인이 다르고, 같은 소모품이라도 차량 규격과 부품 선택에 따라 작업 범위가 달라지기 때문입니다. 그렇다고 가격을 아예 감추면 고객은 비교할 기준을 얻지 못합니다.

먼저 가격이 결정되는 항목을 보여 줍니다. 차량 모델과 연식, 점검 결과, 부품 종류, 작업 범위, 추가 작업 동의 여부를 차례로 설명합니다. 단순 소모품 교체라면 사전에 안내할 수 있는 작업 범위와 포함 항목을 분명히 하고, 증상 진단이 필요한 경우에는 진단 전 비용을 확정할 수 없다는 이유를 적습니다. 점검비와 실제 수리비가 별도인지도 확인 가능한 범위에서 명시합니다.

문의 양식은 불필요하게 길 필요가 없습니다. 차량 정보, 주행거리, 증상이 나타나는 조건, 최근 정비 이력 정도를 요청한 뒤 추가 확인 사항은 상담에서 묻습니다. 고객이 사진을 보내더라도 사진만으로 원인을 단정하지 않는다고 안내합니다.

마지막에는 견적의 유효 범위와 변경 시 설명 절차를 적습니다. 예상과 다른 부품 문제가 발견되었을 때 임의로 작업을 진행한다는 인상을 주지 않도록 해야 합니다. 가격 글의 품질은 낮은 숫자를 앞세우는 데 있지 않고, 고객이 무엇을 비교하고 어느 시점에 동의할지 이해하게 하는 데 있습니다.

견적 사례를 공개할 때에는 실제 작업 범위와 작성 시점, 포함·별도 비용을 적어야 비교가 가능합니다. 사례 차량과 다른 차종에도 같은 금액이 적용된다고 암시하지 않습니다. 고객에게 추가 작업이 필요한 이유를 알릴 때에는 기존 견적과 달라진 항목을 분리해 보여 주는 절차가 신뢰에 도움이 됩니다.

전화 상담에서 안내한 조건과 게시물의 조건이 같은지도 확인합니다. 게시된 가격표가 있더라도 추가 작업의 동의를 생략해도 된다는 뜻은 아닙니다.
