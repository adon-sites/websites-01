## 콘텐츠 주제를 넓힌다는 것은 무엇을 뜻하나요?

주제를 넓힌다는 것은 관련이 적은 키워드를 추가하는 일이 아니라, 업체가 실제로 제공하는 서비스와 고객의 결정을 돕는 질문에서 출발해 범위를 확장하는 일입니다. 넓은 업종명 아래에서 이용 절차, 적용 조건, 이용 후 관리가 각각 다른 답을 필요로 하는지 살핍니다.

서비스를 제공하지 않는 인접 업종의 키워드는 검색량이 높더라도 계획에서 제외합니다. 사이트가 실제로 답할 수 없는 질문을 늘리면 방문자의 기대와 실제 정보가 어긋납니다.

확장의 기준을 먼저 문서로 정해 두면 담당자가 바뀌어도 같은 기준으로 주제를 고를 수 있습니다.

## 기존 페이지는 어떻게 분류하고 정리하나요?

기존 페이지 목록을 질문별로 분류해 이미 다룬 범위를 표시합니다. 제목은 달라도 본문이 같다면 새 글을 만들지 말고 한 페이지로 정리합니다.

아직 답이 없는 질문에는 근거 자료와 검토자를 지정합니다. 산부인과 병원마케팅 사이트라면 의료 정보를 검토할 담당자를, 일반 서비스 사이트라면 운영 정보를 확인할 담당자를 정해 두어야 새 글의 정확성을 유지할 수 있습니다.

분류 작업은 단순한 표로도 충분합니다. 중요한 것은 질문과 담당자가 한눈에 보이도록 정리하는 일입니다.

[표] 기존 페이지 분류표
| 분류 | 판단 기준 | 조치 |
| --- | --- | --- |
| 같은 질문 | 제목만 다르고 본문이 같음 | 한 페이지로 합치기 |
| 답이 없는 질문 | 다루지 않은 결정 단계 | 근거와 검토자 지정 후 작성 |
| 제공하지 않는 서비스 | 실제 운영 범위 밖 | 계획에서 제외 |
| 오래된 정보 | 현재 운영과 다른 내용 | 기준 페이지 기준으로 수정 |

## 지역이나 인접 서비스 이름을 바꿔 복제해도 되나요?

위치와 실제 서비스 가능 범위는 공식 사이트에서 정확하게 안내합니다. 인근 지명을 바꿔 같은 본문을 여러 번 발행하면 내용의 폭이 넓어진 것이 아니라 같은 답이 늘어난 것입니다.

같은 서비스의 다른 이름을 별도 페이지로 만들면 고객이 정보를 비교하기도 어려워집니다. 내용이 겹치는 문서는 합치고, 새로운 상황에서만 달라지는 조건을 설명하는 글을 따로 둡니다.

서비스 이름이 비슷하더라도 이용 조건이 같다면 하나의 페이지로 설명하고 필요한 차이만 덧붙입니다.

## 상위 페이지와 세부 글은 어떻게 이어야 하나요?

상위 페이지와 세부 글 사이의 연결은 방문자가 질문을 따라 이동할 수 있도록 문맥에 맞게 둡니다. 무관한 곳으로 이어지는 연결이 많으면 방문자는 읽던 흐름을 잃습니다.

글을 확장한 뒤에는 모바일 메뉴에서 쉽게 찾을 수 있는지 실제로 눌러 확인합니다. 운영 시간이 자주 바뀌는 업종이라면 최신 안내를 기준 페이지에서 관리하고 세부 글에는 변하는 수치를 줄입니다.

연결 문구는 자세히 보기보다 다음 질문이 무엇인지 드러나는 표현이 읽는 사람에게 더 분명합니다.

## 새 글이 필요한지 판단하는 기준은 무엇인가요?

새로운 주제의 기준은 기존 글과 다른 결정을 돕는 정보가 있는지입니다. 주제 지도를 만들 때 서비스 이름으로만 분류하면 비슷한 질문의 글이 여러 곳에 생기므로, 고객의 상황과 결정 단계, 필요한 다음 행동을 표에 적어 비교합니다.

발행 뒤에는 검색 도구의 수집 오류와 모바일 탐색을 확인하고 어떤 문의가 계속 남는지 봅니다. 관리할 수 있는 검수 속도를 넘어서는 예약 발행을 하지 않는 것도 콘텐츠 품질 관리의 일부입니다.

작은 글 하나라도 발행 전에 담당자가 사실을 확인했는지 기록해 두면 이후 수정이 쉬워집니다.

| 항목 | 적는 내용 | 활용 |
| --- | --- | --- |
| 고객의 상황 | 어떤 상태에서 찾아오는지 | 글의 중심 질문 정하기 |
| 결정 단계 | 알아보기, 비교, 이용 | 글의 역할 나누기 |
| 필요한 다음 행동 | 확인, 신청, 문의 | 연결 경로 설계 |
| 담당 검토자 | 정보를 확인할 사람 | 정확성 유지 |

## 자주 묻는 질문

### 글 수를 늘리면 주제가 넓어지는 건가요?

그렇지 않습니다. 기존 글과 다른 결정을 돕는 정보가 있어야 주제가 넓어진 것이며, 같은 답을 가진 글이 늘어나면 관리 부담만 커집니다.

### 검색량이 높은 인접 업종 키워드는 어떻게 하나요?

실제 제공하지 않는 서비스라면 계획에서 제외합니다. 사이트가 답할 수 없는 질문으로 방문자를 끌어들이면 기대와 실제 정보가 어긋납니다.

### 산부인과 병원마케팅 사이트는 주제를 어떻게 넓혀야 하나요?

실제 진료 범위 안에서 환자의 결정 단계별 질문을 나누고, 각 글을 의료진이 검토하도록 정합니다. 진료하지 않는 분야로 확장하지 않는 것이 기본 원칙입니다.

### 내용이 겹치는 글은 지워야 하나요?

바로 지우기보다 합칠 글과 남길 글을 먼저 정합니다. 합칠 때는 기존 주소의 연결 경로가 끊기지 않도록 점검합니다.

### 모바일 점검은 어떻게 하나요?

새 글이 메뉴에서 쉽게 찾아지는지, 버튼과 연결 경로가 작동하는지 직접 눌러 확인합니다. 화면이 작은 환경에서의 탐색 흐름을 기준으로 봅니다.

### 새 글의 검수 속도는 어떻게 정하나요?

담당자가 정확성을 확인할 수 있는 범위 안에서 발행 속도를 정합니다. 검수가 따라가지 못하는 예약 발행은 오류를 늘리므로 하지 않습니다.
