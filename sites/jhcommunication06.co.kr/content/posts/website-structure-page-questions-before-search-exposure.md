## 페이지 수보다 페이지의 역할이 먼저입니다
네이버 통합검색 같은 곳에서 웹사이트가 눈에 띄길 바란다면 페이지를 많이 만드는 것보다 각 페이지가 어떤 질문을 해결하는지부터 살펴야 합니다. 첫 화면에 회사 소개와 서비스 설명이 뒤섞여 있거나 모든 메뉴가 비슷한 제목을 쓰고 있다면, 검색한 사람이 원하는 곳에 도착하고도 내용을 찾지 못합니다. 순위를 약속하는 광고 문구를 검토하기 전에 사이트 자체의 구조를 먼저 점검해야 하는 이유입니다.

## 대표 페이지와 서비스 페이지를 구분합니다
홈페이지의 대표 페이지에는 사업의 실제 명칭과 제공 범위, 공식 연락 경로가 분명히 있어야 합니다. 서비스별 페이지는 대상과 진행 범위, 문의 전에 확인할 조건을 나누어 적습니다. 같은 서비스 설명에 지역 이름만 바꿔 반복하는 페이지는 이용자가 얻는 차이가 없습니다. 지역별 페이지가 정말 필요하다면 실제 지점이나 서비스 가능 범위에 따라 달라지는 안내가 담겨 있어야 합니다.

서비스 페이지의 제목은 검색한 사람이 입력할 법한 표현과 가까우면서도 실제 내용을 정확히 설명해야 합니다. 과장된 표현이나 제공하지 않는 항목을 암시하는 제목은 이용자의 신뢰를 낮추므로 피합니다.

## 모바일과 링크 상태를 직접 확인합니다
기술적인 점검은 검색 엔진만이 아니라 사람의 이용에도 영향을 줍니다. 휴대전화에서 메뉴와 연락 버튼이 눌리는지, 본문이 화면에서 읽히는지, 내부 링크가 알맞은 페이지로 이어지는지 하나씩 확인합니다. 페이지 제목과 설명 문구는 도착한 화면의 실제 내용과 맞아야 합니다. 예전 주소가 남아 있거나 지운 페이지로 연결되는 링크가 있다면 경로를 바로잡습니다.

점검한 결과는 날짜와 함께 기록해 두면 이후에 문제가 다시 생겼을 때 원인을 찾는 데 도움이 됩니다. 수정이 필요한 항목은 우선순위를 정해 한 번에 한 가지씩 바꾸고 변화를 살핍니다.

## 검색 접근성과 이해하기 쉬운 구성은 서로 다른 작업입니다
검색 최적화는 검색 엔진이 사이트를 읽을 수 있게 정리하는 작업이고, 질문에 바로 답하는 구성은 이용자의 이해를 돕는 작업입니다. 두 개념을 함께 쓰더라도 특정 순위나 노출 기간을 확정해 말할 수는 없습니다. 검색 결과의 변화는 경쟁과 검색 환경의 영향을 받으므로, 한 가지를 고쳤다고 해서 원인을 하나로 단정하지 않는 태도가 필요합니다.

한 번 정리한 구조도 서비스가 바뀌면 달라져야 합니다. 분기마다 메뉴 구성과 대표 페이지의 설명이 지금의 사업과 맞는지 점검하는 일정을 정해 두면 좋습니다.

## 기존 글을 먼저 읽고 겹침을 줄입니다
새 페이지를 만들기 전에 지금 사이트에 있는 글을 목록으로 만들어 제목과 첫 문단, 답하는 질문을 한 줄씩 적어 봅니다. 서로 겹치는 글이 있다면 하나로 합치거나 역할을 나누어 다시 쓰는 편이 이용자에게 낫습니다. 같은 질문에 답하는 글이 여러 개 있으면 방문자는 어느 쪽이 최신인지 알 수 없고, 사이트를 관리하는 사람도 수정할 때 모든 글을 찾아다녀야 합니다. 점검이 끝나면 어떤 글을 고치고 어떤 글을 새로 만들지를 순서대로 적어 일정과 담당자를 정해 둡니다.

## 대행사에 물어볼 질문을 미리 준비합니다
외부 업체와 상담할 때는 어떤 페이지를 수정하려는지, 기존 글과 겹치는 내용은 어떻게 볼 것인지, 수정 전후를 어떤 범위로 측정할지를 물어보세요. 구체적으로 대답하지 못하는 제안은 근거가 약할 수 있습니다. 결과를 약속하는 표현이 있는지도 살펴봅니다.

## 지역 표현과 업종별 기준을 지킵니다
여러 생활권을 겨냥한다면 실제 사업장 주소와 제공 가능 범위를 기준으로 표현을 고릅니다. 법률이나 의료처럼 별도의 광고 기준이 있는 업종은 전문가의 승인 절차를 거쳐야 합니다. 운영자는 색인 상태와 유입, 문의 내용을 구분해 기록하고, 같은 질문의 페이지를 새로 늘리기 전에 기존 문서를 개선합니다. 검색에 잘 보이는 웹사이트는 검색어를 억지로 덧붙인 사이트가 아니라 이용자에게 정확한 길과 답을 알려 주는 사이트에서 출발합니다.

검색어에 맞추려고 실제 사업과 관계없는 단어를 제목에 넣는 방식은 방문자를 잘못된 기대로 이끌 수 있습니다. 페이지에 쓰는 표현은 현재 제공하는 서비스에 한정하고, 변경이 있으면 함께 고칩니다.
