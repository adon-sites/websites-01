## 종료 조건은 서류에 있어도 접근은 시험해야 압니다

대행사를 고를 때 종료 후 인계 조건은 계약서에 한 줄로 적히는 경우가 많습니다. 계정은 사업자에게 이전한다, 원본은 요청 시 제공한다 같은 문장입니다. 문장이 있다는 사실과 실제로 접근할 수 있다는 사실은 다릅니다. 계정이 대행사 개인 메일에 묶여 있거나 원본이 특정 저장 공간에만 있다면 계약이 끝난 뒤에 열어 보지 못할 수 있습니다.

그래서 계약 전에, 또는 계약 초기에 작은 접근 시험을 해 보는 방법이 있습니다. 사업자가 직접 관리자로 들어가 보고, 원본 파일을 직접 내려받아 보고, 수정이 필요할 때 누구에게 어떻게 요청하는지 한 번 지나가 보는 것입니다. 시험은 불신의 표현이 아니라 서로의 책임을 같은 그림으로 맞추는 절차입니다.

## 계정은 소유자가 누구로 등록되어 있는지부터 봅니다

광고 계정, 지도 정보, 블로그, 홈페이지 관리 화면은 각각 소유자와 관리자 권한이 따로 있습니다. 대행사가 만들어 운영하더라도 소유자는 사업자 쪽 이름이어야 하고, 사업자가 관리자로 직접 들어갈 수 있어야 합니다. 이 점은 서비스 화면의 권한 목록에서 직접 확인합니다.

확인할 때는 채널별로 표를 만들어 계정 이름, 소유자, 관리자 목록, 복구 연락 수단을 적습니다. 복구용 이메일이나 휴대전화 번호가 대행사 담당자 개인 것으로 되어 있다면 담당자가 바뀌거나 계약이 끝났을 때 문제가 될 수 있습니다. 가능하면 사업자가 관리하는 연락 수단으로 바꾸어 두고, 변경이 어려운 사정이 있다면 이유와 대안을 문서에 남깁니다.

## 사진과 디자인 원본은 사용 권리와 파일 위치를 함께 확인합니다

촬영한 사진과 만든 디자인은 완성본만 받아서는 나중에 고치기 어렵습니다. 원본 파일, 편집 가능한 형식, 글꼴과 사용한 소재의 사용 범위를 함께 받을 수 있는지 견적 단계에서 묻습니다. 사진 속 사람이나 공간의 사용 동의가 필요한 경우 누가 확인했는지도 기록으로 남깁니다.

파일 위치도 시험 대상입니다. 공유 폴더 주소를 받았다면 대행사 계정에서 로그아웃한 상태로 접근해 열리는지 봅니다. 받은 파일을 사업자 쪽 저장 공간에 옮겨 두는 시점과 주기를 정하면 계약 종료 시점에 한꺼번에 받아야 하는 부담이 줄어듭니다.

## 오류 수정과 수정 요청의 길도 함께 지나가 봅니다

접근 권한이 있어도 어떻게 고쳐야 하는지 모르면 소용이 없습니다. 시간표가 바뀌었을 때 각 매체를 고치는 담당과 기한이 어떻게 되는지, 요청은 어떤 경로로 하는지를 견적서에 적어 둡니다. 채널별로 담당이 다르다면 역할 기준으로 나누어 기록합니다.

실제 연습으로 가벼운 수정 요청 하나를 보내 보는 방법도 있습니다. 예를 들어 영업시간 문구 하나를 고치게 하고, 요청부터 공개 화면 반영까지 걸린 과정과 보고 형식을 살펴봅니다. 보고서에 적힌 수정 내역이 실제 공개 화면과 일치하는지 대조해 보면 협업 방식의 차이가 드러납니다.

## 비용 항목과 접근 항목을 같은 문서에서 읽습니다

담당자가 바뀌는 경우도 시험 범위에 넣습니다. 대행사 쪽 담당이 교체되어도 접근 권한과 작업 기록이 새 담당에게 이어지는지, 사업자 쪽 담당이 바뀌었을 때 관리자 등록을 어떻게 바꾸는지를 미리 적어 두면 운영이 갑자기 멈추는 일을 줄일 수 있습니다.

견적서를 볼 때 매체 비용, 대행 수수료, 제작비, 촬영과 사이트 수정 비용을 분리해 읽는 것과 같은 방식으로 접근 항목도 분리합니다. 계정 이전, 원본 전달, 종료 후 일정 기간의 문의 대응이 비용에 포함되는지 별도 비용이 드는지를 확인해 둡니다.

접근 시험의 결과도 문서로 남깁니다. 어떤 계정을 어느 날 확인했고 어떤 파일을 받았는지를 간단한 표로 정리하면 계약 종료 시점에 비교할 기준이 됩니다. 검색 노출이 단기간에 올라간다는 말은 업무 범위를 대신하지 못하므로, 약속이 아니라 확인 가능한 작업과 권한을 기준으로 삼습니다.

## 정리와 확인

계약 전 시험은 계정 소유와 복구 수단, 원본과 사용 권리, 파일 위치, 수정 요청 경로, 비용 포함 여부의 다섯 가지로 요약할 수 있습니다. 서비스마다 권한 구조와 이전 방식이 다르고 계약 조건도 상황에 따라 달라질 수 있습니다. 현재 사용하는 서비스의 안내와 계약 상대의 조건을 직접 확인한 뒤 적용하시기 바랍니다.
