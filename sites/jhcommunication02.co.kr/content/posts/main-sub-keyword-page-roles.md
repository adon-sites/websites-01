## 메인키워드와 서브키워드는 무엇이 다른가요?

메인키워드는 사이트가 다루는 넓은 분야를 나타냅니다. 다만 그 한 단어만으로는 방문자가 무엇을 궁금해하는지 알 수 없습니다. 서브키워드는 그 분야 안의 서비스, 상황, 시점처럼 질문을 구체적으로 좁히는 단어입니다.

둘을 연결하려면 단어를 어디에 넣을지보다 페이지 사이의 역할을 먼저 정해야 합니다. 치과 병원광고실행사와 키워드를 정리할 때도 메인 분야 아래에 어떤 질문들이 있는지 목록으로 만들어 보면 중복되는 글이 쉽게 드러납니다. 지역이나 서비스 이름을 모든 제목에 똑같이 붙이는 방식은 각 글의 답이 다르지 않다면 중복이 됩니다.

## 페이지마다 맡는 역할은 어떻게 정하나요?

메인 서비스 페이지에는 제공 범위와 주요 선택 기준을 담습니다. 세부 글은 한 가지 질문에 답하고, 기준 페이지의 해당 항목으로 이어지게 합니다. 예를 들어 넓은 주제 아래 예약 절차와 관리 방법이 따로 있다면 두 글을 읽는 사람의 행동이 다르므로 글도 분리됩니다.

글을 쓰기 전에 읽은 사람이 무엇을 확인하게 되는지 한 줄로 적어 둡니다. 이 문장이 다른 글과 같다면 합치는 쪽을 먼저 검토합니다.

| 페이지 | 맡는 키워드 | 독자가 하는 행동 |

| 메인 서비스 페이지 | 넓은 분야를 나타내는 키워드 | 범위와 선택 기준 확인 |
| 세부 안내 글 | 구체적인 질문을 담은 키워드 | 한 가지 조건 확인 |
| 예약·문의 페이지 | 신청과 관련된 키워드 | 실제 신청 진행 |

## 내부 링크는 어떤 문단에서 연결해야 하나요?

내부 링크는 관련성이 있는 문단에서 자연스럽게 이어져야 합니다. 비용 조건을 읽던 방문자가 최신 안내를 확인하고 싶을 때 해당 안내로 이동할 수 있는 흐름이 좋습니다. 링크 문구에 같은 키워드를 기계적으로 반복하거나 관련 없는 페이지를 수십 개 연결하면 오히려 탐색이 어려워집니다.

상위 페이지에서 세부 글로, 세부 글에서 정확한 기준 페이지로 돌아갈 수 있는지 확인합니다. 한 페이지에 연결이 너무 많으면 선택지가 흐려지므로 방문자에게 필요한 길만 남깁니다.

연결을 점검할 때는 담당자 한 명이 직접 메뉴를 눌러 따라가 보고, 막히거나 되돌아오는 지점을 메모해 두면 좋습니다. 이렇게 모은 메모는 어느 페이지의 역할을 다시 나눌지 정하는 근거가 됩니다.

## 키워드 지도를 만든 뒤에는 무엇을 대조하나요?

지도를 만들었다면 글 제목보다 실제 본문을 대조합니다. 제목은 다르지만 두 페이지가 같은 설명을 하고 있지는 않은지, 오래된 정보가 서로 부딪히지는 않는지 살핍니다. 이 점검은 한 번으로 끝나지 않고 글이 추가될 때마다 반복해야 합니다.

검색 결과에서의 위치는 여러 요인의 영향을 받기 때문에 특정 구성만으로 결과를 장담할 수 없습니다. 메인과 서브의 연결은 검색엔진을 위한 장치이기 전에 사람이 필요한 답을 따라갈 수 있게 하는 정보 구조입니다.

## 서브키워드는 어떤 기준으로 고르면 좋을까요?

단어의 크기보다 답의 차이를 기준으로 삼습니다. 표현이 다르더라도 같은 답이라면 한 페이지에서 함께 설명하고, 조건이 달라져 답이 바뀐다면 별도 문서로 나눕니다.

배치를 마친 뒤에는 검색자의 입장에서 메뉴를 따라가 봅니다. 넓은 설명에서 세부 조건으로 내려가는 경로와, 세부 질문에서 공식 안내로 돌아오는 경로가 모두 필요한 경우가 많습니다. 주소를 바꾸거나 글을 합칠 때에는 기존 링크를 점검해 끊어진 경로가 남지 않게 합니다.

## 자주 묻는 질문

### 모든 글에 메인키워드를 넣어야 하나요?

모든 글에 반복해서 넣을 필요는 없습니다. 글의 질문에 자연스럽게 필요한 경우에만 쓰고, 페이지의 역할이 분명하면 연결은 구조가 만들어 줍니다.

### 치과 병원광고실행사와 키워드 지도를 만들 때 먼저 할 일은 무엇인가요?

기존 페이지의 제목과 질문을 목록으로 정리하는 일입니다. 겹치는 질문이 어디에 있는지 확인한 뒤 새 글이 필요한지 결정합니다.

### 내부 링크는 많을수록 좋은가요?

많다고 좋지 않습니다. 관련성이 있는 몇 곳만 남기고, 방문자가 다음에 확인할 내용으로 이어지는 연결을 우선합니다.

### 두 글이 비슷하면 꼭 합쳐야 하나요?

같은 답을 하고 있다면 합치는 편이 낫습니다. 조건이 달라 답이 달라진다면 나눠 두고 서로 연결합니다.

### 키워드를 연결하면 순위가 오르나요?

순위는 여러 요인에 영향을 받으므로 특정 구조만으로 결과를 단정할 수 없습니다. 방문자가 답을 따라가기 쉬워졌는지를 기준으로 판단합니다.

### 글을 합치거나 주소를 바꿀 때 주의할 점은 무엇인가요?

기존 링크가 끊어지지 않는지 확인합니다. 이전 주소로 들어오던 방문자가 새 안내로 이동할 수 있게 연결 경로를 점검합니다.
