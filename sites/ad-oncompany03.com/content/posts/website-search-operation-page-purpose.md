## 현재 페이지가 어떤 질문에 답하는지 확인합니다
검색 유입을 늘리고 싶다면 먼저 지금 있는 페이지가 어떤 질문에 답하고 있는지 확인해야 합니다. 대표 페이지에 모든 서비스와 지역을 한꺼번에 넣으면 방문자는 필요한 내용을 찾기 어렵습니다.

반대로 제목만 다르고 내용이 거의 같은 페이지가 여럿이면 검색어를 넓혀도 이용자가 얻는 새 정보가 없습니다. 각 페이지에 하나의 분명한 목적을 두고 그 목적에 맞는 사실을 검수하는 것이 운영의 출발점입니다.

질문을 확인하는 방법으로는 검색창에 자동으로 나타나는 연관 표현과 고객이 실제로 전화나 메시지로 묻는 말을 함께 살펴보는 것이 쉽습니다. 두 가지가 겹치는 표현은 우선 다룰 가치가 크고, 겹치지 않는 표현은 별도 확인이 필요합니다. 이 목록이 페이지 목적을 정하는 기초 자료가 됩니다.

## 페이지 목록을 만들어 중복과 빈 곳을 찾습니다
사이트의 모든 페이지를 목록으로 만들어 제목, 핵심 질문, 제공하는 서비스, 마지막으로 확인한 날짜를 적어 봅니다. 중복되는 질문은 하나로 합칠 수 있는지 보고, 과정이나 대상이 달라지는 경우에만 별도 설명을 검토합니다.

첫 문단은 제목의 질문에 직접 답하고 그 뒤에 판단에 필요한 조건을 적습니다. 연락 버튼만 여러 번 놓고 안내 정보는 비워 두면 업체를 비교하는 사람에게 도움이 되지 않습니다.

목록을 만든 뒤에는 같은 질문에 답하는 페이지끼리 묶어 어느 페이지를 대표로 둘지 정합니다. 대표가 아닌 페이지는 내용을 합치거나 대표 페이지로 연결하고, 남겨 둘 이유가 있다면 차이를 첫 문단에 분명히 씁니다. 이렇게 정리하면 사이트 전체의 구조가 단순해지고 관리할 대상도 줄어듭니다.

## 지역 정보는 실제 제공 범위와 연결합니다
지역 이름은 방문 서비스인지, 사업장에서 이용하는 서비스인지, 다른 지역에서도 이용할 수 있는지에 따라 쓰임이 달라집니다. 해당하지 않는 지역을 넓혀 적지 않습니다.

제목을 고치거나 새 글을 올릴 때는 주소가 바뀌었는지, 기존 링크가 제대로 이어지는지, 모바일에서 중요한 문장이 읽히는지도 함께 확인합니다. 검색 로봇이 접근할 수 있는지 보는 기술 점검과 독자가 답을 찾는지 보는 내용 점검은 둘 다 필요합니다.

제공 범위를 적을 때는 실제 계약이나 운영 기준과 맞는지 담당자가 직접 확인합니다. 방문 서비스의 가능 지역이나 출장 비용 같은 조건은 문의가 몰리는 부분이므로 별도 항목으로 두는 것이 좋습니다. 수정 후에는 이전 주소에서 새 주소로 연결되는지, 사이트 지도가 갱신되었는지도 점검합니다.

운영 체계는 복잡할 필요가 없습니다. 월초에 페이지 목록을 열어 지난달 바뀐 서비스나 조건이 있는지 확인하고, 해당 페이지를 먼저 고친 다음 새 글의 주제를 정합니다. 월말에는 문의 내용에서 반복된 질문과 페이지의 답을 비교해 부족한 곳을 기록합니다. 이 두 가지 습관만으로도 오래된 정보가 남는 일이 줄어들고 페이지마다 목적이 선명해집니다. 담당자는 수정 내역을 짧게라도 남겨 두어 다음 달의 판단 근거로 삼는 것이 좋습니다. 대행사가 있다면 같은 형식의 기록을 공유받아 함께 검토합니다.

## 대행 업체와는 작업 범위와 검증 방식을 문서로 확인합니다
검색 상단에 노출시켜 준다는 말만으로는 계약 내용을 판단하기 어렵습니다. 어떤 페이지를 수정할 수 있는지, 원고의 사실 확인은 누가 하는지, 수정 내역과 측정 결과를 어떻게 공유하는지 물어봅니다.

특정 순위를 내세우는 주장보다 실제 작업 범위와 확인 방법을 문서로 받아 두는 편이 낫습니다.

대행 계약서나 제안서에는 작업 항목별 완료 기준을 적도록 요청합니다. 예를 들어 제목 수정이라면 대상 페이지 수와 수정 전후 내용을 보고서로 제공한다는 식입니다. 이렇게 하면 결과를 숫자로만 판단하지 않고 실제로 무엇이 바뀌었는지 확인할 수 있습니다.

## 짧은 기간의 증감으로 원인을 단정하지 않습니다
검색어별 방문 변화와 방문 이후의 행동을 함께 관찰하되, 며칠 사이의 오르내림만으로 원인을 단정하지 않습니다. 계절이나 휴일 같은 외부 요인이 겹칠 수 있습니다.

많이 발행하는 속도보다 확인 가능한 정보를 꾸준히 갱신하고, 페이지마다 고유한 답을 유지하는 일이 운영의 기준이 됩니다.

변화를 관찰할 때는 최소 몇 주 단위로 같은 기준의 기록을 비교합니다. 수정한 날짜, 바꾼 내용, 이후 방문 경로를 한 표에 적어 두면 원인과 결과를 연결해 생각하기 쉽습니다. 기록이 없으면 어떤 수정이 도움이 되었는지 알 수 없어 같은 시행착오를 반복하게 됩니다.
