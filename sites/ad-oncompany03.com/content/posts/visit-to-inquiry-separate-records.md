## 방문 수와 문의 수는 왜 따로 기록해야 하나요?

노출, 클릭, 사이트 방문, 문의는 서로 다른 행동입니다. 앞 단계의 숫자가 늘었다고 뒤 단계가 같은 비율로 늘어나는 것은 아닙니다. 하나의 숫자로 묶어 보면 어느 단계에서 사람이 빠져나갔는지 알 수 없습니다.

어디에서 들어온 사람이 어떤 페이지를 보고 연락했는지 알아야 고칠 곳이 보입니다. 안과 병원마케팅 보고서에 단계별 숫자가 나뉘어 있는지부터 확인하는 것이 출발점입니다. 단계별로 나누면 클릭은 많은데 방문이 적은지, 방문은 많은데 문의가 적은지 같은 구체적인 문제가 눈에 들어옵니다.

## 유입 경로별로 무엇이 다른가요?

검색 광고, 자연 검색, 블로그, 지도 정보는 각각 다른 경로입니다. 지도에서 길 찾기를 누른 사람과 서비스 설명을 읽고 상담을 신청한 사람은 목적이 다릅니다. 여러 채널을 함께 운영할 수는 있지만 경로별 비용과 작업 내용은 구분해 적어야 합니다.

광고 집행비와 대행료, 콘텐츠 제작비를 하나의 월 금액으로만 제시하면 비교가 어렵습니다. 항목을 나누어 받아야 어느 경로가 어떤 결과로 이어지는지 따져 볼 수 있습니다. 같은 광고라도 경로에 따라 방문자의 목적이 다르다는 점을 보고서에서도 구분해 읽어야 합니다.

[표] 단계별로 나누어 기록할 항목
| 단계 | 기록할 내용 | 함께 볼 것 |
| --- | --- | --- |
| 노출 | 광고나 검색에 보인 횟수 | 노출된 경로 |
| 클릭 | 링크를 누른 횟수 | 누른 페이지 |
| 방문 | 사이트에 들어온 횟수 | 머문 페이지 |
| 문의 | 전화나 상담 요청 | 문의 전 본 페이지 |

## 방문 뒤에 문의가 이어지지 않는 이유는 무엇일 수 있나요?

방문자가 필요한 정보를 찾지 못했을 가능성을 먼저 봅니다. 제목에서 비용을 암시했는데 본문에 기준이 없거나, 운영 시간이 바뀌었는데 지도에는 예전 시간이 남아 있으면 문의까지 가기 어렵습니다.

모바일에서 문의 버튼이 제대로 눌리는지, 관련 서비스 페이지로 이동할 수 있는지도 직접 확인합니다. 제목이 약속한 내용이 페이지 본문에 실제로 있는지도 비교해 보면 어긋난 곳을 쉽게 찾을 수 있습니다. 페이지를 오래 읽었다는 사실만으로 만족했다고 단정하지 않습니다.

## 지역 정보는 어떻게 맞춰야 하나요?

사업장의 실제 위치와 제공 범위를 기준으로 지역 정보를 정합니다. 지점이 없는 동네 이름만 바꾼 페이지를 복제하는 방식은 방문자를 혼란스럽게 합니다.

어떤 서비스에 문의가 늘고 어떤 질문이 반복되는지는 현장 담당자와 공유해 설명을 보강합니다. 안과 병원마케팅에서는 이 공유 과정이 있어야 광고 문구와 실제 안내가 어긋나지 않습니다. 보고서의 방문자 수만으로 문의나 매출을 예측하는 일은 위험합니다. 반복되는 질문이 있다면 답을 해당 페이지 가까이에 두어 방문자가 다시 찾아다니지 않게 합니다.

## 대행사를 고를 때는 무엇을 확인하나요?

측정 도구와 계정의 소유, 자료 접근 권한, 보고 주기, 수정 책임자를 확인합니다. 집행 전후에 무엇을 바꾸었는지 기록해야 광고 변경과 홈페이지 개선의 효과를 구분할 수 있습니다.

[표] 대행사 확인 항목
| 항목 | 확인할 내용 | 이유 |
| --- | --- | --- |
| 측정 도구 | 어떤 도구로 재는지 | 숫자의 기준 확인 |
| 계정 소유 | 누가 계정을 갖는지 | 종료 후 자료 보존 |
| 보고 주기 | 월별 보고 기준 | 비교 가능성 |
| 변경 기록 | 집행 전후의 수정 사항 | 효과 구분 |

전체 흐름을 본다는 말은 모든 숫자를 한데 묶는다는 뜻이 아닙니다. 각 단계의 실제 행동을 분리해서 본다는 뜻입니다. 월별 비교 기준도 처음에 정해 두어야 합니다. 기준이 중간에 바뀌면 지난달과 이번 달의 숫자를 같은 선에서 비교할 수 없게 됩니다.

## 자주 묻는 질문

### 방문이 늘었는데 문의가 늘지 않으면 광고를 중단해야 하나요?

바로 중단하기보다 방문 뒤 페이지에서 정보가 부족한지 먼저 확인합니다. 유입 경로별로 문의 비율이 어떻게 다른지도 함께 봅니다.

### 안과 병원마케팅 보고서에서 가장 먼저 볼 항목은 무엇인가요?

단계별 숫자가 따로 나뉘어 있는지입니다. 하나의 합계로만 제시된 보고서는 원인을 찾기 어렵습니다.

### 금액을 한 덩어리로 받아도 되나요?

권하지 않습니다. 광고 집행비와 대행료, 제작 항목을 나누어 받아야 비교와 점검이 가능합니다.

### 모바일에서는 무엇을 확인하나요?

문의 버튼이 정상적으로 작동하는지와 관련 페이지로 이동하는지를 직접 눌러 확인합니다. 화면이 작아 버튼이 가려지는 경우도 살핍니다.

### 페이지 체류 시간이 길면 좋은 신호인가요?

그렇게 단정할 수 없습니다. 정보를 찾느라 오래 머물렀을 수도 있으므로 문의로 이어졌는지와 함께 봅니다.

### 대행사가 바뀌면 자료는 어떻게 되나요?

계정의 소유와 자료 접근 권한이 사업자에게 있어야 자료가 보존됩니다. 계약 단계에서 확인해 둡니다.
