## 이름이 서로 다르면 어떤 문제가 생기나요?

간판의 영문 이름, 지도의 한글 이름, 홈페이지 로고, 페이지 제목이 서로 다르면 방문자는 같은 장소인지 따져 보아야 합니다. 예약 문자에 적힌 이름과 길에서 보이는 간판이 다르면 도착한 뒤에도 맞는 곳인지 망설이게 되고, 접수 창구에서 이름을 다시 확인하는 일도 생깁니다.

그렇다고 법적 명칭, 브랜드명, 지점명을 모두 하나의 형태로 합치는 것은 아닙니다. 각각 쓰이는 자리가 다르기 때문에 먼저 이름의 목록을 만들고 역할을 정하는 일이 필요합니다. 안과 병원마케팅 안내에서도 이 목록이 기준이 됩니다.

## 먼저 무엇을 확인해야 하나요?

실제 간판과 사업자 표시, 지도 등록명, 예약 문자에서 쓰는 이름을 한곳에 모아 비교합니다. 각 이름이 어떤 자리에서 쓰이는지 정리한 뒤 첫 화면과 위치 안내에서 서로의 관계를 설명합니다.

지점이 여러 곳이라면 영문 브랜드만 크게 보여 주지 않습니다. 예약의 대상이 되는 지점 이름을 주소 가까이에 적어 두면 방문자가 어느 곳으로 가야 하는지 바로 알 수 있습니다.

| 이름의 종류 | 맡는 역할 | 표시할 위치 |
| --- | --- | --- |
| 법적 명칭 | 사업자 정보 표시 | 하단 정보 영역 |

| 지점 이름 | 예약 대상 구분 | 주소와 예약 화면 |
| 영문 표기 | 간판과 외부 표기 | 위치 안내의 보조 설명 |

## 검색 결과에서는 이름을 어떻게 보여 주나요?

검색 결과에서 제목이 잘리는 경우를 생각해 식별 가능한 부분이 앞에 오도록 씁니다. 영문 약어만 앞에 두면 비슷한 이름과 구별하기 어려울 수 있습니다. 한글 이름과 지점 구분을 앞쪽에 두는 편이 알아보기 쉽습니다.

페이지마다 이름의 표기를 다르게 바꿔 검색어를 늘리려는 방식은 권하지 않습니다. 방문자가 예약 문자와 간판을 대조해 같은 곳임을 확인할 수 있는 일관성이 우선이고, 그것이 결국 검색 이용자의 신뢰를 만듭니다.

## 로고와 예약 시스템의 표기는 어떻게 점검하나요?

로고 이미지의 대체 텍스트와 머리글에 있는 글자 이름도 살핍니다. 로고가 불러와지지 않거나 화면을 소리로 읽는 기능을 쓸 때에도 병원과 지점의 이름을 알 수 있어야 합니다. 안과 병원마케팅 사이트에서는 이런 접근성 점검이 빠지기 쉬운 부분입니다.

영문 표기의 띄어쓰기와 대소문자가 달라서 예약 시스템의 검색 결과가 갈라지는 일도 있습니다. 직접 여러 형태로 검색해 보고 같은 지점이 하나로 묶여 나오는지 시험합니다. 결과가 갈라진다면 표기 규칙을 문서로 정해 두고 담당자가 같은 형태로 입력하게 합니다.

## 이름을 바꾼 뒤에는 무엇을 정리하나요?

이름을 바꾼 뒤에는 지도와 외부 프로필, 오래된 안내 파일에 남은 표기를 목록으로 만들어 하나씩 고칩니다. 과거의 이름으로 검색되었을 때 현재 병원과의 연결을 설명할 수 있어야 합니다.

합병이나 이전이 함께 있었다면 옛 이름으로 예약한 사람이 받은 문자와 새 간판의 관계를 따로 알려야 합니다. 상담원이 전화에서 어떤 이름으로 인사하는지도 맞추고, 접수 화면에 이전 명칭이 남아 있지 않은지 확인합니다.

| 점검 대상 | 확인할 내용 | 남기기 쉬운 문제 |
| --- | --- | --- |
| 지도와 외부 프로필 | 등록명 수정 | 예전 이름이 그대로 노출 |

다국어 표기도 한 번 정한 공식 명칭을 따르게 합니다. 임의 음역을 여러 개 만들기보다 방문자가 간판과 예약 확인서에서 같은 단어를 찾을 수 있게 하는 편이 낫습니다. 이름의 목적은 검색 결과에 여러 형태로 나타나는 것이 아니라 방문자가 같은 장소를 확신하고 도착하도록 돕는 데 있습니다.

## 자주 묻는 질문

### 영문 이름과 한글 이름 중 무엇을 기준으로 삼나요?

하나를 고르기보다 각각의 역할을 정합니다. 간판과 예약 문자에서 방문자가 대조하는 이름을 기준으로 삼으면 혼란이 줄어듭니다.

### 지점이 여러 곳이면 이름은 어떻게 쓰나요?

영문 브랜드만 크게 쓰지 말고 예약 대상인 지점 이름을 주소와 가까운 곳에 적습니다. 방문자가 어느 지점으로 가야 하는지 한눈에 알 수 있어야 합니다.

### 안과 병원마케팅 글에서 이름 표기는 어떻게 맞추나요?

글 안의 이름도 공식 명칭과 같은 형태로 맞춥니다. 페이지마다 다르게 쓰면 방문자가 같은 곳인지 다시 확인해야 합니다.

### 로고의 대체 텍스트는 왜 확인하나요?

로고가 보이지 않거나 화면을 소리로 읽을 때도 이름을 알 수 있어야 하기 때문입니다. 대체 텍스트에 병원과 지점의 이름이 들어 있는지 점검합니다.

### 이름을 바꾸면 예전 이름은 어떻게 처리하나요?

예전 이름으로 검색된 경우에도 현재 병원과의 연결을 설명할 수 있게 안내를 남깁니다. 지도와 외부 프로필의 표기도 함께 고칩니다.

### 다국어 표기는 어떻게 관리하나요?

지점별로 정한 공식 명칭을 따르게 합니다. 임의 음역을 여러 개 만들면 같은 곳이 다른 곳처럼 보일 수 있습니다.
