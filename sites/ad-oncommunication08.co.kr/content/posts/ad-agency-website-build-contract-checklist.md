## 두 가지를 한 업체에 맡기면 무엇이 편하고 무엇이 위험한가요?

장점은 일정과 자료를 한곳에서 주고받는다는 점입니다. 광고 문구와 홈페이지 내용이 같은 담당자에게서 나오므로 메시지가 어긋날 가능성도 줄어듭니다. 플레이스 상위노출처럼 지도 검색 안내와 홈페이지 정보를 맞춰야 하는 작업이라면 더욱 그렇습니다.

위험은 책임 범위가 흐려지는 데 있습니다. 누가 문구를 확인하고 누가 수정을 처리하는지 정해 두지 않으면 문제가 생겼을 때 서로 상대의 일이라고 생각하기 쉽습니다. 계약 전에 홈페이지의 목적을 문의, 예약, 상품 안내처럼 구체적으로 적고, 승인 책임자를 사업자 쪽에서 한 사람 정해 두는 것이 우선입니다. 여러 사람이 각자 수정을 요청하면 일정이 늘어나고 최종 내용을 확인하기 어려워집니다.

## 계약서에는 어떤 업무를 나누어 적어야 하나요?

정보 구조 설계, 원고 작성, 디자인, 개발, 도메인과 호스팅 관리, 검색 등록, 유지보수를 하나씩 나누어 적어야 합니다. 뭉뚱그려 제작 일체라고만 적으면 나중에 무엇이 포함이었는지 다투게 됩니다.

[표] 계약서에 나누어 적을 업무와 확인 사항
| 업무 | 확인할 내용 | 책임 주체 |
| --- | --- | --- |
| 원고 작성 | 사실관계 확인 담당 | 사업자가 최종 확인 |
| 디자인·개발 | 수정 가능 횟수와 범위 | 제작 업체 |
| 도메인·호스팅 | 명의와 관리자 계정 | 사업자 명의 권장 |
| 사진·서체 | 사용 허락 범위 | 출처 확인 후 계약에 명시 |

콘텐츠의 사실관계는 사업자가 확인하고, 대행사는 편집과 기술 구현에 책임을 지는 구조가 분명해야 합니다. 고객 후기를 쓰려면 사용 동의 여부도 함께 점검합니다.

## 프로젝트가 끝난 뒤 도메인과 계정은 누가 갖나요?

계약 단계에서 정해 두지 않으면 가장 자주 분쟁이 되는 부분입니다. 도메인, 관리자 계정, 원본 파일을 종료 후 누가 보유하는지 미리 적어 두고, 인계 항목은 계약서와 완료 보고서에서 각각 확인합니다.

담당자가 바뀌어도 접속할 수 있도록 계정 목록을 별도로 보관하고, 비밀번호는 문서에 직접 적지 않고 안전한 방식으로 전달합니다. 인계가 끝난 뒤에는 대행사 쪽 권한이 어디까지 남는지도 확인해 두면 이후 운영이 편해집니다. 유지보수를 계속 맡길 경우에는 접근 범위를 필요한 만큼으로 제한합니다.

## 광고를 눌러 도착한 페이지는 무엇을 점검하나요?

광고 문구와 도착 페이지의 답이 맞아야 합니다. 특정 서비스를 광고했는데 일반 회사 소개만 나온다면 방문자는 원하는 조건을 찾지 못하고 떠납니다. 플레이스 상위노출 작업과 연결된 홈페이지라면 운영시간과 위치 정보가 지도 안내와 같은지도 확인합니다.

[표] 공개 전에 직접 시험할 항목
| 점검 항목 | 확인 방법 | 이상이 있을 때 |
| --- | --- | --- |
| 모바일 문의 버튼 | 실제 휴대전화로 눌러 보기 | 제작 업체에 수정 요청 |
| 개인정보 안내 | 입력 전에 안내 문구가 보이는지 확인 | 안내 문구 추가 |
| 운영시간·위치 | 실제 운영 정보와 대조 | 사업자가 정확한 정보 전달 |

시험은 제작 업체의 설명을 믿고 넘기기보다 사업자가 직접 해 보는 것이 가장 확실합니다. 광고에서 안내한 내용과 페이지 내용이 다르면 문의가 늘어도 적합한 문의가 줄어들 수 있습니다.

## 공개한 뒤에는 어떤 기준으로 운영 상태를 보나요?

수정 요청을 처리하는 기한과 오류가 생겼을 때의 연락 경로를 확인합니다. 성과 보고서에서는 클릭 수만이 아니라 도착 페이지에서 이탈하는 지점과 실제 문의가 적합했는지를 살핍니다.

특정 검색 순위를 약속하는 설명보다 결과를 확인하고 고칠 수 있는 구조가 장기 운영에 도움이 됩니다. 홈페이지 제작을 함께 맡길지는 한 업체가 모든 일을 한다는 편의보다, 각 책임을 계약과 계정 권한으로 분명히 나눌 수 있는지로 판단하는 것이 좋습니다.

## 자주 묻는 질문

### 계약 전에 가장 먼저 정할 것은 무엇인가요?

홈페이지의 목적과 승인 책임자입니다. 문의, 예약, 상품 안내 중 무엇이 핵심인지 정하면 필요한 업무 범위도 함께 정리됩니다.

### 도메인은 제작 업체 명의로 등록해도 되나요?

가능하면 사업자 명의로 등록하는 편이 안전합니다. 업체 명의일 경우 종료 후 이전 절차와 비용을 계약서에 적어 둡니다.

### 플레이스 상위노출 작업과 홈페이지 제작은 같이 진행하는 것이 좋은가요?

함께 하면 정보를 맞추기 쉬운 장점이 있습니다. 다만 두 업무의 범위와 책임을 나누어 적고 결과를 약속하는 표현이 없는지 확인합니다.

### 고객 후기를 홈페이지에 넣어도 되나요?

사용 허락을 확인한 경우에만 넣습니다. 개인을 알아볼 수 있는 내용은 제외하고 사실과 다른 내용이 없는지 점검합니다.

### 공개 뒤에 수정이 필요하면 어떻게 요청하나요?

계약서에 정한 연락 경로로 요청하고 처리 기한을 확인합니다. 수정 내용과 날짜를 기록해 두면 이후 점검이 쉬워집니다.

### 성과 보고서에서 클릭 수만 보면 안 되나요?

클릭 수는 일부일 뿐입니다. 도착 페이지에서 이탈하는 지점과 문의가 실제 서비스에 맞았는지도 함께 살펴야 합니다.
