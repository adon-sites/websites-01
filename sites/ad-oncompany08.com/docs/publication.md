# 기본 설정과 다음 단계

## 현재 상태

대표 카드용 6편과 6장만 사이트별 신규 제작합니다. 기존 대표 글/이미지와 다른 신규 사이트의 글/이미지를 복제하지 않습니다. 회사 소개와 공통 사업자·상담·병원 링크는 사용자 지정 공통 요소입니다.

원고와 캐러셀 상태는 private_ready이고 원고의 publishedAt은 없습니다. private_carousel_preparation 단계는 정확히 6편만 허용합니다. 카드와 ItemList는 표시되는 제목·순서·글 주소·이미지 주소가 같습니다. 모든 글은 이 사이트 내부 상세 페이지로 연결되며 목록 첫 페이지에 함께 표시됩니다.

canonical·OG URL·구조화 데이터·RSS는 company.json의 origin을 사용합니다. 내부 링크와 이미지 경로는 루트 상대경로여서 각 사이트 주소에서 읽습니다.

검색은 robots.txt Disallow: /, HTML noindex/nofollow/noarchive, X-Robots-Tag 차단으로 준비합니다. 실제 접근 차단은 Sites의 소유자 전용 범위를 유지합니다. 사이트맵과 RSS 글 항목은 비어 있습니다. 비공개 배포 성공과 공개·검색 수집·색인·캐러셀 노출은 별개입니다.

## 콘텐츠 검수

각 대표 슬롯의 기준 원고 본문 길이 이상으로 독립 집필하며 공통 연락처·링크·소제목은 본문 분량에서 제외합니다. 제목/설명/본문 완전 중복0, 25자 이상 동일 문장0, 원시 빈도 문자4그램 코사인0.65미만을 점검합니다. 기존 원고·이전 초안·참고 본문·신규 원고 전체에 대조하고 상위 근접문서2편 전문을 작성자 외 검토자가 읽습니다. 수치만으로 의미검수 완료를 판정하지 않습니다. 이미지도 별도 신규 생성하고 파일/시각 중복을 점검합니다.

## 이후 일반 원고

25개 설정 완료 보고 후 사용자 지시에 따라 일반 원고를 작성·검수·발행합니다. 대표 슬롯에 연결되지 않은 글은 이미지 필드가 있어도 자동 제거되어 원고형으로 표시됩니다. 목록은 10편 단위로 페이지 이동이 생성됩니다. 모든 상세 글 하단에는 지정 병원 링크5개와 상담 수단이 자동 포함됩니다.

## 도메인과 공개

1. 사이트별 도메인 선택과 소유 권한·DNS·HTTPS 확인.
2. company.json의 origin/customDomain을 해당 사이트 주소로 함께 변경.
3. 공개 원고의 검수와 실제 공개 시각 확인; 원고와 대표 슬롯을 published로 전환.
4. 별도 공개 지시에 따라 publication stage=public, allowArticleRendering=true, allowSearchIndexing=true, company searchIndexing=true로 변경 후 생성·검증·배포.
5. Sites 접근 범위를 공개로 바꾸는 작업도 별도 수행.
6. 비로그인 방문에서 원고·이미지·연락처·metadata·ItemList·사이트맵·RSS 검증.
7. 실제 받은 소유확인 값으로 검색 도구 등록·수집 요청 후 결과 확인.

검색 수집·색인·노출을 확인하지 않은 상태를 완료로 기록하지 않습니다.
